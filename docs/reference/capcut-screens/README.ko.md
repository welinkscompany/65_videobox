# 캡컷 화면 캡처를 여기에 넣어 주세요

owner가 캡처한 캡컷 실물 화면을 모으는 자리입니다.

## 왜 이 폴더가 따로 있나

캡컷 배치를 판단할 때 **짐작이 아니라 실물을 근거로** 쓰기 위해서입니다
(`docs/implementation-plan.ko.md` §4.1이 "캡컷을 벤치마킹한다"고 정했습니다).

AI는 대화로 받은 그림을 디스크에 저장하지 못합니다. 그래서 **파일은 owner가 여기에
넣어 주셔야** 다음 세션에서도 열어 볼 수 있습니다. 대화에만 있으면 세션이 끝나면
사라집니다.

## 넣는 법

이 폴더에 PNG를 그대로 복사하시면 됩니다. 이름은 어느 화면인지 알아볼 수 있게:

    01-홈.png
    02-편집기-미디어.png
    03-편집기-전환.png
    ...

## 이미 글로 옮겨 둔 것

`docs/reference/capcut-observed-2026-08-22.ko.md`에 2026-08-22 캡처에서 읽은 것을
전부 적어 두었습니다 — 탭 구성, 왼쪽 목록의 분류, 실제 항목 이름까지.
**그림이 없어도 그 문서만으로 작업할 수 있습니다.** 그림은 대조용입니다.

## 커밋해도 되나

됩니다. 다만 캡처가 쌓이면 저장소가 무거워지므로, **같은 화면의 새 캡처는 옛것을
덮어씁니다.** 히스토리로 남길 필요가 있는 화면만 날짜를 붙여 따로 둡니다.
