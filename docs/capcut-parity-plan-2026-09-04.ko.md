# 캡컷 온라인 세부 대조와 적용 계획서 (2026-09-04)

owner 지시로 캡컷 온라인 편집기를 **버튼·기능 단위로 하나씩 열어보고**, 그중
우리 시스템에 적용할 수 있는 것을 정리한 계획서다.

앞 문서 `capcut-parity-audit-2026-09-04.ko.md`가 "무엇이 다른가"였다면, 이 문서는
**"무엇을 어떻게 가져오는가"**다.

## 0. 전제 (owner가 정한 것)

- **웹 버전은 캡컷을 벤치마킹한다. 버튼 이름과 내용도 동일하게.**
- **AI(로컬·Hermes 유진)는 뼈대가 아니라 옆에서 도와주는 역할.**
- `이야기` 단계는 **편집기 안 도구로 옮긴다.**
- **색·팔레트는 유지**한다(§6 승인 대상).
- 점검·계획이 먼저고, 고치는 순서는 owner가 이 문서를 보고 정한다.

지키는 경계: 캡컷에 **없는** 기능 버튼은 새로 만들지 않는다
(`decisions/2026-08-30-capcut-button-level-parity.ko.md`). 사람 게이트 셋(제목
선택·대본 확정·업로드)은 없애지 않는다(`decisions/2026-08-16`).

## 2. 치수 — 제일 먼저 할 것

| 항목 | 캡컷 | 우리 | 적용안 |
|---|---|---|---|
| 기준 글자 | **12px** | 16px | `:root` 기준을 12px로. 척도 전체를 다시 잡는다 |
| 실제 많이 쓰는 크기 | 14px(63곳) · 12px(39곳) · 10px(4곳) | 16px 기준 척도 | 본문 14 / 보조 12 / 라벨 10 |
| 버튼 높이 | **32px 하나로 통일**(15개가 정확히 32) | 28·29·32·36·52 뒤섞임 | 기본 32, 아이콘 단추 정사각 |
| 제일 큰 버튼 | 50px — `내보내기` **하나뿐** | 80px `+ 새 프로젝트 만들기` | 주 버튼 하나만 크게 |

**이게 뿌리다.** 기준이 16px이면 같은 정보에 화면을 1.3~2배 쓰고, 자리가 모자라
스크롤이 생기고, 스크롤을 없애려 탭에 우겨넣게 된다. owner가 말한
"글자가 커서 버튼이 다 커지고 어거지로 우겨넣게 된다"가 이 연쇄다.

**주의:** 이 변경은 화면 전체를 한꺼번에 바꾼다. 되돌리기 쉽게 **단독 커밋**으로
하고, 바꾼 뒤 주요 화면을 다시 재서 넘침·잘림을 확인한다.

## 3. 편집기 골격 — 세로 띠 두 개

캡컷 편집기(1672×771 실측):

```
┌──┬──────────┬─────────────────────────────┬────────┬──┐
│세│  패널     │        미리보기               │ 속성    │세│
│로│ ~293px   │                              │ ~266px │로│
│띠│          ├─────────────────────────────┤        │띠│
│72│          │        타임라인               │        │57│
└──┴──────────┴─────────────────────────────┴────────┴──┘
```

- **왼쪽 세로 띠(~72px)**: 미디어 · 템플릿 · 요소 · 오디오 · 텍스트 · 캡션 ·
  대본 · 편집효과 · 전환 · 필터 · 브랜드 키트 · 플러그인 — **12개**, 62px 간격,
  아이콘 + 10px 글자
- **패널(~293px)**: 지금 고른 띠 항목 **하나의 내용만**
- **오른쪽 속성 패널(~266px)** + **오른쪽 세로 띠(~57px)**: 사전 설정 · 기본 ·
  텍스트에서 음성으로 · 애니메이션
- **패널 접기**: 왼쪽 가장자리 `›` 손잡이. 접으면 미리보기·타임라인이 화면을 다 쓴다

**우리는:** 왼쪽이 가로 탭 4개(미디어·오디오·자막·전환), 오른쪽 세부 정보는
**보이는 높이의 2.44배**(433px 창에 1055px)로 세로 스크롤.

**적용안 — 이게 owner가 "스크롤 말고 탭으로"라고 한 것의 정답이다:**

1. 왼쪽 가로 탭 → **세로 아이콘 띠**로 바꾼다. 가로 폭은 남고 세로가 모자라므로,
   이동을 세로로 옮기면 패널 높이가 통째로 살아난다.
2. 오른쪽 세부 정보를 **속성 세로 띠로 쪼갠다.** 캡컷 오른쪽 패널이 짧은 이유는
   내용이 적어서가 아니라 다른 속성 묶음이 **아래로 안 쌓이고 띠로 빠져 있기**
   때문이다. 우리 1055px는 대부분 "쌓인 것"이라 이 하나로 크게 준다.
3. **패널 접기 손잡이**를 넣는다.

## 4. 패널별 대조와 적용안

### 4.1 미디어

캡컷: 패널 맨 위에 **`업로드`** 주 버튼(전체 폭) → 그 아래 보조 아이콘 단추 2개 →
홍보 카드 → **2열 썸네일 격자**(파일명 캡션). 워크스페이스 이름이 패널 머리에 있다.

우리: `파일 추가`·`내레이션`·`촬영본`·`자료실에서 가져오기` 4개가 나란히,
그 아래 `전체/영상/그림`, `모든 방향/가로/세로`, `격자로 보기/줄로 보기`까지
필터가 3줄.

**적용안**
- `업로드`를 패널 맨 위 **전체 폭 주 버튼** 하나로. 나머지(내레이션·촬영본·
  자료실)는 보조 단추나 `···`로 내린다.
- 필터 3줄 → 검색칸 + **칩 한 줄**로 접는다(캡컷 오디오 패널 방식).
- 썸네일 2열 격자 유지.

### 4.2 오디오

캡컷: 패널 머리에 **탭 `음악` / `음향 효과`**(청록 밑줄) → `음악 검색` + 필터
아이콘 → **칩 한 줄**(background music, phonk, Happy…) → `카테고리` + `모두 보기`
→ **가로 스크롤 썸네일 줄**(`›` 화살표) → `추천` → 세로 결과 목록(썸네일 48px +
제목 + `길이 · 아티스트` 2줄).

**핵심: 둘러보기는 가로로, 결과만 세로로.** 그래서 스크롤이 안 생긴다.

**적용안**
- 우리 음악·효과음을 **한 패널 안 두 탭**으로 합친다(지금은 자리가 나뉘어 있다).
- 카테고리는 **가로 스크롤 줄**로. 세로로 쌓지 않는다.
- 결과 행은 썸네일 + 2줄(제목 / 길이·출처)로 압축.

### 4.3 텍스트

캡컷: 패널 머리 탭 **`텍스트 템플릿` / `텍스트 편집효과`** → `기본` 묶음에
**`머리글 추가`** · **`본문 추가`** 두 개의 전체 폭 버튼 → `모두` / `상업적 자료`
칩 → 템플릿 줄들(각 줄 제목 + `모두 보기`, 가로 스크롤).

**중요: 캡컷은 `텍스트`(화면 위 글자)와 `캡션`(자막)을 완전히 분리한다.**

**적용안**
- 우리는 둘을 `자막` 하나로 뭉쳐 놨다. **분리한다.**
- 화면 위 글자는 `텍스트`, 말자막은 `캡션`.
- `머리글 추가` / `본문 추가` 두 버튼 패턴을 그대로 쓴다.

### 4.4 캡션 ← **우리가 제일 많이 배울 곳**

캡컷: **큰 카드 4개**, 각각 아이콘 + 제목 + 한 줄 설명.

| 카드 | 설명 |
|---|---|
| **자동 캡션** 💎 | 동영상에서 음성을 자동으로 인식합니다. |
| **수동 캡션** | 수동으로 캡션을 입력하세요. |
| **캡션 파일 업로드** | 지원: .srt, .ass, .lrc |
| **자동 가사** | 노래 가사를 자동으로 인식합니다. |

카드 하나가 패널 전체 폭, 높이 ~80~90px. **컨트롤이 아니라 "무엇을 할지" 넷을
먼저 고르게 한다.** 고른 뒤에야 세부 설정이 나온다.

우리: 자막 칸을 열면 글꼴·크기·색·굵게·기울임·자간·위치·정렬… **컨트롤이 한꺼번에**
쏟아진다. 그래서 1055px가 됐다.

**적용안**
- 우리 `자막` 진입을 **카드 3장**으로 바꾼다: `자동 캡션`(faster-whisper 이미 있음)
  / `수동 캡션` / `캡션 파일 업로드`(.srt 이미 지원).
- `자동 가사`는 **안 만든다**(우리 범위 밖).
- 세부 스타일 컨트롤은 **캡션을 고른 뒤 오른쪽 속성 패널**로 보낸다.
  이 하나로 오른쪽 칸 스크롤 대부분이 사라진다.

### 4.5 대본 ← **`이야기`를 옮길 자리**

캡컷: 상단 안내 카드(미리보기 그림 + "동영상의 음성에서 대본을 생성합니다.
대본을 편집하여 동영상을 편집할 수 있습니다." + `확인`) → 본 카드
**`대본 기반 편집`** + "대본을 편집하여 동영상을 빠르게 편집하세요." →
**`소스 언어 선택`** 드롭다운(영어(미국)) → **`텍스트 변환할 트랙 선택`**
드롭다운(동영상 트랙 1) → **`텍스트 변환`** 주 버튼(전체 폭, 청록).

**293px 폭에 안내 + 라벨 2개 + 드롭다운 2개 + 버튼 1개가 다 들어간다.**

**적용안 — owner가 정한 "이야기를 편집기 안 도구로"가 정확히 이 자리다.**
- 왼쪽 띠에 **`대본`** 항목을 만들고, 지금 `/create`에 있는 네 갈래(대본 붙여넣기 /
  찍어둔 영상 / 목소리만 / 아무것도 없음)를 **캡션 패널식 카드**로 넣는다.
- 유진 질문 4개와 기획 요약은 **관문이 아니라** 이 패널 안에서 이어지게 한다.
  (= owner가 말한 "AI는 도와주는 역할")
- 드롭다운 + 전체 폭 주 버튼 패턴을 그대로 쓴다.

### 4.6 오른쪽 속성 패널

캡컷(텍스트 선택 시): 머리 `기본` + 닫기 `×` → 글 내용 입력칸 → **`변형`** 묶음
(되돌리기 아이콘) → `확대` 슬라이더 + 숫자칸 `57 %` → `위치` `X: -277` `Y: 37` →
`회전` `0°` → `브랜드 키트에 추가`.

오른쪽 세로 띠: `사전 설정` · `기본` · `텍스트에서 음성으로` · `애니메이션`.

**적용안**
- 우리 `세부 정보` 칸을 **속성 세로 띠 + 짧은 패널**로 바꾼다.
- 숫자는 **슬라이더 + 숫자칸 쌍**으로(지금 우리는 입력칸만 있거나 버튼만 있다).
- `텍스트에서 음성으로`가 속성 띠에 있다는 점이 중요하다 — 우리 `내레이션`도
  같은 자리로 갈 수 있다.

### 4.7 타임라인

캡컷: 도구 줄에 왼쪽 `분할`·`삭제`·`다운로드`, **가운데 재생 버튼 + `00:00:00 |
00:19:28`**, 오른쪽 확대·축소·맞춤·미리보기 토글. 그 아래 눈금(00:00, 00:10…),
트랙(텍스트 조각 주황, 영상 썸네일 줄, 왼쪽에 스피커·연필 아이콘).

**적용안**
- **재생 버튼을 타임라인 도구 줄 가운데**에 놓고 `현재 | 전체`를 옆에 붙인다.
  지금 우리는 재생기가 미리보기 안에만 있고, **미리보기가 실패하면 통째로
  사라진다**(`preview-stage.tsx:250`) — owner가 "스페이스바가 안 먹는다"고 한
  원인이다. 타임라인에 두면 미리보기 상태와 무관하게 항상 보인다.
- 우리 편집 도구 6개(실행 취소·다시 실행·나누기·앞과 붙이기·빼기·다음 장면에도)를
  캡컷처럼 **왼쪽에 아이콘으로** 모은다.

### 4.8 내보내기

캡컷: 버튼에 붙은 **팝오버 하나**.
- `검토를 위해 공유` — "사람들이 회원님의 동영상에 댓글을 추가할 수 …"
- `프레젠테이션으로 공유` — "사람들이 내 동영상을 볼 수만 있습니다."
- `소셜 미디어에 공유` — TikTok · TikTok Ads Manager · YouTube · YouTube Shorts ·
  Facebook 페이지 · Instagram 릴스 · 예약
- `다운로드` + `···`

**설정 벽이 없다.** 무엇을 할지 먼저 고르고, 설정은 그 다음에 나온다.

우리: `확인과 내보내기` 화면에 자막 만들기·완성본 만들기·CapCut 초안 만들기·
상태 다시 확인이 상태 문구와 함께 널려 있다.

**적용안**
- `내보내기` 팝오버로 합친다: `다운로드`(완성본 MP4) · `공유 링크`(이미 있음) ·
  `유튜브`(승인됨) · `CapCut 초안`.
- **캡컷에 없는 소셜 대상은 안 만든다.**
- 자막·완성본 만들기 같은 **준비 단계는 내보내기 안에 숨기지 말고** 눌렀을 때
  알아서 되게 하거나, 못 하면 **왜 못 하는지 그 자리에서** 말한다.
  (지금은 `완성본 만들기`가 눌리는데 "자막이 낡았다"는 이유를 안 알려준다)

## 5. 이름 대조표

| 우리 | → 캡컷 이름 |
|---|---|
| 자막 | **캡션** (그리고 화면 위 글자는 **텍스트**로 분리) |
| 자막 만들기 | **자동 캡션** |
| 내레이션 | **텍스트에서 음성으로** |
| 목소리 등록·클론 | **사용자 지정 음성** |
| 완성본 만들기 / 내보내기 | **내보내기** 하나로 |
| 세부 정보 | **기본** (+ 속성 띠 분리) |
| 파일 추가 | **업로드** |
| 나누기 | **분할** |

**캡컷에 이름이 없는 것**(유진, 동영상 번역기, 촬영본 정리)은 억지로 끼우지 않고
따로 정한다. **우리에 없는 캡컷 항목**(템플릿·요소·편집효과·필터·브랜드 키트·
플러그인)은 만들지 않는다.

## 6. 실행 계획

뿌리부터 잡는 순서. 각 묶음은 **단독 커밋**으로 하고, 끝날 때마다 실기계에서 잰다.

| # | 묶음 | 하는 일 | 왜 이 순서인가 |
|---|---|---|---|
| 1 | **치수 기준** | 기준 12px, 버튼 32px 통일, 척도 재정리 | 뿌리. 먼저 하면 3·4번 일이 줄어든다 |
| 2 | **입구** | `+ 새로 만들기` 하나로. 새 프로젝트가 빈 편집기 오류로 안 떨어지게 | owner가 제일 먼저 막힌 자리 |
| 3 | **골격** | 왼쪽 세로 띠 + 오른쪽 속성 띠 + 패널 접기 | 스크롤 2.44배가 여기서 사라진다 |
| 4 | **캡션/텍스트 분리** | 캡션 카드 3장, 스타일은 속성 패널로 | 오른쪽 칸이 짧아진다 |

| 8 | **업로드** | 바깥 파일 끌어다 놓기(`dataTransfer.files`) | 지금 0곳 |
| 9 | **내보내기** | 팝오버로 합치기 | |

## 7. 안 하는 것 / 아직 모르는 것

- **색·팔레트는 안 건드린다**(§6 승인 대상).
- 캡컷의 템플릿·요소·편집효과·필터·브랜드 키트·플러그인은 **안 만든다**.
- 자동 가사, 소셜 대상 다수도 **안 만든다**.
- **"느리다"의 원인은 아직 안 쟀다.** §6 11번에서 재고 나서 말한다.
- 캡컷 쪽에서 아직 안 본 것: `템플릿`·`요소`·`편집효과`·`전환`·`필터` 패널 내부,
  `다운로드`를 눌렀을 때 나오는 설정. 필요하면 같은 방법으로 더 볼 수 있다.
