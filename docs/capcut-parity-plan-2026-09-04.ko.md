# 캡컷 온라인 전수 조사와 적용·완성 계획서 (2026-09-04)

owner 지시로 캡컷 온라인 편집기를 **직접 조작하며 버튼·기능을 하나씩 확인**하고,
그것을 **우리 시스템에 어떻게 적용해 완성할지까지** 적은 계획서다.

앞 문서 `capcut-parity-audit-2026-09-04.ko.md`는 "무엇이 다른가"였다.
이 문서는 **"캡컷은 정확히 어떻게 생겼고, 우리는 무엇을 어떻게 바꿔 끝내는가"**다.

## 0. 전제 (owner가 정한 것)

- **웹 버전은 캡컷을 벤치마킹한다. 버튼 이름과 내용도 동일하게.**
- **AI(로컬·Hermes 유진)는 뼈대가 아니라 옆에서 도와주는 역할.**
- `이야기` 단계는 **편집기 안 도구로 옮긴다.**
- **색·팔레트는 유지**한다(§6 승인 대상이라 건드리지 않는다).

지키는 경계: 캡컷에 **없는** 기능 버튼은 새로 만들지 않는다
(`decisions/2026-08-30`). 사람 게이트 셋(제목 선택·대본 확정·업로드)은 유지한다
(`decisions/2026-08-16`).

## 4. 패널 전수 명세

### 4.1 미디어

```
[업로드]                       ← 전체 폭 주 버튼 (257×36)
[휴대폰] [화면]                ← 보조 아이콘 단추 2개
┌ 홍보 카드 ────────────┐
│ Seedance 2.5          │ 14px
│ 30초 클립 및 정교한 편집 │ 12px
│ [지금 사용해 보기]      │ 231×28
└───────────────────────┘
파일 격자 2열 (파일명 12px)
```

**적용:** `업로드` 하나를 맨 위 전체 폭으로. 지금 우리는 `파일 추가`·`내레이션`·
`촬영본`·`자료실에서 가져오기` 4개가 나란하고 그 아래 필터가 3줄이다 →
**검색칸 + 칩 한 줄**로 접고 나머지는 `···`로 내린다. 홍보 카드 자리는 **유진 추천**
자리로 쓴다(= AI를 조력자로).

### 4.2 오디오

```
[음악] [음향 효과]              ← 패널 머리 탭 (청록 밑줄)
[🔍 음악 검색        ] [필터]   ← h=34
(background music)(phonk)(...)  ← 칩 h=20
카테고리              모두 보기  ← 14px + 14px
[가로 스크롤 썸네일 ▸]
추천                            ← 14px
 ▢ Hope. City pop.(1145157)     ← 제목 14px
   02:11 · table_1              ← 메타 12px
```

**핵심: 둘러보기는 가로, 결과만 세로.**

**적용:** 음악·효과음을 **한 패널 두 탭**으로 합친다(지금은 자리가 나뉘어 있다).
카테고리는 가로 스크롤 줄. 결과 행은 썸네일 + 2줄(제목 14 / `길이 · 출처` 12).

### 4.3 텍스트

```
[텍스트 템플릿] [텍스트 편집효과]  ← 머리 탭
기본
  [머리글 추가]                   ← 미리보기 글자 20px
  [본문 추가]                     ← 14px
(모두)(상업적 자료)                ← 칩
인기                    모두 보기
[가로 격자 ▸]
KATSEYE👠 / 픽셀 비드👾 / 기본형 …
```

**적용:** 화면 위 글자를 `텍스트`로 **분리 신설**. `머리글 추가` / `본문 추가`
두 버튼을 그대로 쓴다. 템플릿 줄은 안 만든다(범위 밖).

### 4.4 캡션 ← **제일 많이 배울 곳**

카드 4장인데, **누르면 그 자리에서 펼쳐져** 컨트롤이 나온다(아코디언).

```
┌ 자동 캡션 💎 ───────────────┐
│ 동영상에서 음성을 자동으로 인식합니다. │ 12px
│ 동영상에 사용되는 언어           │ label 14px
│ [영어(미국)            ▾]      │ 드롭다운 h=30
│ [생성]                        │ 217×32
└──────────────────────────────┘
┌ 수동 캡션 ──────────────────┐
│ 수동으로 캡션을 입력하세요.       │
└──────────────────────────────┘
┌ 캡션 파일 업로드 ─────────────┐
│ 지원: .srt, .ass, .lrc         │
└──────────────────────────────┘
┌ 자동 가사 ──────────────────┐  ← 안 만듦
```

**컨트롤을 먼저 보여주지 않는다. "무엇을 할지"를 먼저 고르게 하고, 고른 카드
안에서만 설정이 열린다.**

우리는 자막 칸을 열면 글꼴·크기·색·굵게·기울임·자간·위치·정렬이 **한꺼번에**
쏟아진다. 그래서 오른쪽 칸이 1055px(보이는 높이의 2.44배)가 됐다.

**적용:** 카드 3장 — `자동 캡션`(faster-whisper 이미 있음) / `수동 캡션` /
`캡션 파일 업로드`(.srt 이미 지원). **자동 가사는 안 만든다.**
스타일 컨트롤은 전부 **오른쪽 속성 패널로 이동**. 이 하나로 스크롤 대부분이 사라진다.

### 4.5 대본 ← **`이야기`를 옮길 자리**

```
┌ 안내 카드(닫힘 가능) ──────────┐
│ 동영상의 음성에서 대본을 생성합니다.│
│ 대본을 편집하여 동영상을 편집할 수 │
│ 있습니다.              [확인]   │ ← 50×28
└──────────────────────────────┘
┌ 대본 기반 편집 ───────────────┐
│ 대본을 편집하여 동영상을 빠르게    │
│ 편집하세요.                    │
│ 소스 언어 선택                  │ label
│ [영어(미국)            ▾]       │
│ 텍스트 변환할 트랙 선택           │ label
│ [동영상 트랙 1          ▾]       │
│ [텍스트 변환]                   │ 전체 폭 주 버튼
└──────────────────────────────┘
```

**293px에 안내 + 라벨 2 + 드롭다운 2 + 버튼 1이 전부 들어간다.**

**적용:** 왼쪽 띠에 `대본`을 만들고, 지금 `/create`의 네 갈래(대본 붙여넣기 /
찍어둔 영상 / 목소리만 / 아무것도 없음)를 **캡션식 아코디언 카드 4장**으로 넣는다.
유진 질문·기획 요약은 **관문이 아니라 이 패널 안에서** 이어진다.

## 5. 오른쪽 속성 — 선택에 따라 바뀐다

**속성 세로 띠가 고정이 아니다. 고른 것에 따라 항목이 달라진다.**

| 고른 것 | 속성 띠 |
|---|---|
| 영상 클립 | 기본 · 배경 · 스마트 도구 · 애니메이션 · **속도** |
| 글자 | 사전 설정 · 기본 · **텍스트에서 음성으로** · 애니메이션 |

### 5.1 영상 클립 `기본`

```
기본                          × ← 16px, h=52
마스크
  ⃠ 없음                      › ← 값이 보이는 행 + 화살표
색상 조정
  기본,HSL,곡선                › ← 12px 요약
혼합                          ↺ ← 되돌리기
  모드
  [일반                  ▾]
  불투명도
  ──────●──── [100] %      ◇ ← 슬라이더+숫자+키프레임
손떨림 보정 💎            [토글]
```

### 5.2 `속도` — **우리와 뜻이 다른 자리**

```
속도                          ×
[일반] [곡선]                    ← 탭
기본
  속도    [    ] x
  기간    [19.9] s
  음조                    [토글]
  부드러운 슬로우 모션 💎    [토글]
```

**캡컷은 `속도`와 `기간`을 같이 보여주고 연동한다** — 배속을 바꾸면 길이가 바뀐다.
우리는 배속이 길이를 안 바꾼다(기억 `videobox-speed-means-something-different-than-capcut`).
**이름을 같이 쓰려면 동작도 같아야 한다.** 안 맞추면 이름만 같고 뜻이 달라 더 헷갈린다.
→ 이건 별도 결정이 필요하다(§10에 올림).

### 5.3 적용

우리 `세부 정보` 칸(1055px)을 **속성 세로 띠 + 짧은 패널**로 바꾼다. 쓸 무늬:

1. **값이 보이는 행 + `›`** — 눌러야 하위 패널이 열린다(마스크, 색상 조정)
2. **슬라이더 + 숫자칸 + 단위** 3종 세트
3. **토글** — 켜고 끄는 것
4. **드롭다운** — 고르는 것 (글꼴 15개가 여기로)
5. **되돌리기 아이콘** — 묶음마다

## 6. 타임라인

**도구줄이 선택에 따라 바뀐다.**

| 상태 | 도구 |
|---|---|
| 아무것도 선택 안 함 | 2개 |
| 클립 선택 | **9개** — 분할·삭제·회전·자르기·좌우반전·복제 등 |

```
[][][🗑][↻][⬚][⧎][⧉][✂][⊺][⤓▾]   ▶ 00:00:00 | 00:19:28   [✦][⊂⊃][⊖]──●──[⊕][⛶][🖵]
00:00      00:10      00:20      00:30      00:40      00:50      01:00
        [🏷][A]                                        ← 텍스트 트랙
[🔊][✏] [▬▬▬ video clip 00:19:28 ▬▬▬]                 ← 영상 트랙(썸네일 줄)
```

- **재생 버튼이 타임라인 도구줄 가운데** + `현재 | 전체`
- 트랙 왼쪽에 **스피커·연필** 아이콘(음소거·편집)
- 클립에 **이름 + 길이**가 박혀 있음
- 타임라인 본체는 **`<canvas>`** (DOM 아님)

**적용 — owner가 "스페이스바가 안 먹는다"고 한 것의 해결책:**
우리 재생기는 미리보기 안에만 있고 **미리보기가 실패하면 통째로 사라진다**
(`preview-stage.tsx:250`, `currentMedia` 없으면 재생줄 미렌더). 그래서 눌러도 아무
일이 없었다. **재생 버튼을 타임라인 도구줄로 옮기면** 미리보기 상태와 무관하게
항상 보인다. 우리 편집 도구 6개도 캡컷처럼 왼쪽에 아이콘으로 모은다.

## 7. 내보내기

**팝오버 2단계.** 설정 벽이 없다.

```
1단계                          2단계 (‹ 뒤로)
내보내기                        ‹ 내보내기 설정
 💬 검토를 위해 공유         ›   (해상도·형식·화질…)
    사람들이 댓글을 추가…
 🖵 프레젠테이션으로 공유     ›
    사람들이 볼 수만…
 소셜 미디어에 공유
 [TikTok][TikTok Ads]
 [YouTube][YT Shorts]
 [Facebook][Instagram][예약]
 ⤓ 다운로드                ›  [···]
```

**적용:** 우리 `확인과 내보내기` 화면(버튼·상태 문구가 널림)을 **`내보내기` 팝오버**로
합친다: `다운로드`(완성본 MP4) · `공유 링크`(있음) · `유튜브`(승인됨) · `CapCut 초안`.
**캡컷에 없는 소셜 대상은 안 만든다.**

그리고 **준비 단계를 사용자에게 떠넘기지 않는다.** 지금은 `완성본 만들기`가 눌리는데
실패하고, 화면은 "완성본을 만들지 못했어요"만 말한다. 진짜 이유는 API에만 있었다
(`stale_output_asset: subtitle freshness changed` = 자막을 먼저 만들어야 함).
**눌렀을 때 알아서 되게 하거나, 못 하면 왜 못 하는지 그 자리에서 말한다.**

## 8. 반복해서 나오는 UI 무늬 6가지

캡컷 전체를 관통하는 무늬다. **이걸 공용 부품으로 만들면 화면마다 다시 안 짜도 된다.**

| # | 무늬 | 쓰이는 곳 |
|---|---|---|
| 1 | **아코디언 카드** — 제목 + 한 줄 설명, 누르면 그 안에서 설정이 열림 | 캡션, 대본 |
| 2 | **값이 보이는 행 + `›`** — 현재 값 보여주고 눌러야 하위 패널 | 마스크, 색상 조정, 다운로드 |
| 3 | **구역 제목 + `모두 보기` + 가로 격자 `▸`** | 전환, 효과, 필터, 텍스트, 오디오 |
| 4 | **검색 + 칩 한 줄** | 오디오, 효과 |
| 5 | **슬라이더 + 숫자칸 + 단위 (+ 키프레임 ◇)** | 불투명도, 확대, 속도 |
| 6 | **문맥 도구줄** — 고른 것에 따라 도구가 바뀜 | 타임라인, 속성 띠 |

## 12. owner 결정이 필요한 것

1. **`속도`의 뜻** — 캡컷은 배속과 길이가 연동된다. 우리는 안 된다. 이름을 맞출 때
   동작도 맞출지, 아니면 이름을 다르게 갈지 정해야 한다(§5.2).
2. **실행 순서** — 위 1~11번 순서로 갈지, owner가 지금 제일 답답한 것부터 갈지.
3. **`유진` 자리** — 홍보 카드 자리(미디어 패널 상단)를 유진 추천으로 쓰자는 게
   이 계획서의 제안이다. 다른 자리를 원하면 지금 정하는 게 싸다.
