# 캡컷 전면 채택 + 우리 자산 얹기 — 최종 계획서 (2026-09-04)

owner 지시로 **로그인 직후 첫 화면부터** 캡컷 전체를 조사하고, 우리 시스템을
어떻게 다시 짤지 적은 계획서다. 앞선 두 문서(`capcut-parity-audit`,
`capcut-parity-plan`)를 대체한다.

## 0. owner가 정한 방향

> "유료 버전 제외하고 모든 캡컷 다시 확인해. (…) 초기 로그인하자마자 나오는
> 화면부터 모두 분석을 해서 우리 시스템에 적용하도록 만들어. 대신에 우리는
> **나만의 비롤+음성 이라는 자산으로 만드는거고, 그걸 우리는 최대한 재사용**하는
> 거잖아. 그래서 **캡컷의 기능 다 가져오고 나머지는 우리걸 추가하는 형태**로."

정리하면 **뼈대 = 캡컷, 차별점 = 내 자산 재사용**이다.

- 캡컷의 **무료** 기능과 구조를 그대로 가져온다. 버튼 이름·내용까지 동일하게.
- 유료(크레딧·Pro)에 걸린 기능은 **가져오지 않는다.**
- 그 위에 **나만의 B-roll + 나만의 음성**을 얹고, **재사용을 최대화**한다.
- AI(로컬·유진)는 뼈대가 아니라 **자산을 고르고 채우는 조력자**.
- 색·팔레트는 유지(§6 승인 대상).

## 2. 캡컷 전체 지도

### 2.1 로그인 직후 첫 화면 (`/my-edit`)

**첫 화면은 라이트, 편집기는 다크다.** (우리는 승인된 다크를 유지하므로 이건 안 따른다.)

│ AI로 만들기(12px)│            [동영상][디자인]  ← 모드 토글
│  디자인 스튜디오  │   ┌──────────────────────────────┐
│  동영상 스튜디오  │   │ 프롬프트 입력                   │

│ ───────────    │   [카드][카드][카드][카드][카드][카드]

**핵심 구조 셋**
1. **왼쪽 사이드바가 항상 있다**(228px). 구역 제목(12px) + 항목(14px).
   "지금 어디 있는지"가 늘 보인다.
2. **주 버튼은 `+ 새로 만들기` 하나**. 맨 위, 전체 폭, 색으로 튄다.
3. 본문은 **카드 가로 줄 + 칩**. 세로로 안 쌓는다.

## 3. 무료/유료 경계 — 무엇을 안 가져오는가

캡컷은 AI 기능을 **크레딧**으로 판다(owner 계정 잔액 150, 상단에 `업그레이드`
상시 노출). 편집기 안에서는 💎·`Pro` 표시가 붙는다.

**유료라서 안 가져오는 것**
- `자동 캡션` 💎 — 다만 **우리는 같은 일을 로컬 faster-whisper로 무료로 한다**
- `손떨림 보정` 💎, `부드러운 슬로우 모션` 💎, `슈퍼 슬로우 모션`
- `동영상 스튜디오`(Seedance) · `AI 캐릭터` · `AI 모델` · `제품 URL로 광고 생성` ·
  `디자인할 텍스트` · `이미지 스튜디오` · `음성 변조기` · `일괄 편집` ·
  `긴 동영상을 짧은 동영상으로`
- 유료 템플릿·요소·편집효과·필터·브랜드 키트·플러그인

**범위 밖이라 안 가져오는 것** (`decisions/2026-08-30`, §2.1)
- 템플릿 · 요소 · 편집효과 · 필터 · 브랜드 키트 · 플러그인 · 자동 가사
- 전문 색보정, 고급 마스크, 멀티캠

**가져오는 것 (캡컷 구조·이름 그대로)**
- 첫 화면 골격(사이드바 + `+ 새로 만들기` + 카드 줄)
- 편집기 골격(세로 띠 둘 + 패널 + 접기 + 문맥 도구줄)
- 미디어 · 오디오 · 텍스트 · 캡션 · 대본 · 전환 패널
- 속성 패널 무늬(값 보이는 행 + 슬라이더·숫자·토글·드롭다운)
- 내보내기 팝오버 2단계
- 최근 프로젝트 카드(버튼 없는 카드)

**여기서 생기는 우리 강점:** 캡컷이 크레딧으로 파는 것(캡션 생성, 텍스트에서
음성으로, 목소리)을 **우리는 로컬에서 공짜로** 한다. 이건 화면에 드러내야 한다.

## 4. 우리 차별점이 들어갈 자리 — 나만의 B-roll + 음성

owner 말대로 **자산을 만들고 최대한 재사용**하는 게 우리 제품이다.
캡컷 구조 어디에 얹을지 자리를 정한다.

### 4.1 이미 있는 것 (새로 안 만들어도 됨)

| 자산 | 현재 상태 |
|---|---|
| B-roll·촬영본 | 자동 색인 + **의미 검색** 됨 (기억 `videobox-broll-semantic-yes-music-no`) |
| 음악·효과음 | 자동 색인 + 의미 검색 됨 |
| 내 목소리 | Chatterbox(MIT) 클론, `start-voice.ps1`로 켬 |
| 자막 생성 | faster-whisper 로컬, 실측 검증됨 |
| 유진의 장면별 자산 고르기 | 있음 (`DirectorCandidate`) |

**부품은 다 있다.** 문제는 부르는 자리가 흩어져 있고 캡컷과 이름·모양이 다른 것.

### 4.2 얹을 자리

| 캡컷 자리 | 우리가 얹는 것 |
|---|---|
| 사이드바 `AI로 만들기` 구역 | → **`내 자산`** 구역으로 대체: `내 B-roll` · `내 목소리` · `음악·효과음` |
| 미디어 패널 상단 홍보 카드 | → **유진 추천**("이 장면엔 이 촬영본이 어울려요") |
| 미디어 패널 검색 | → **의미 검색**(이미 있음). 캡컷은 파일명만 찾는다 |
| 오디오 패널 `음악`/`음향 효과` 탭 | → 그대로 + **내 목소리** 탭 추가 |
| 캡션 `자동 캡션` 💎 | → **무료**(로컬 faster-whisper). 배지를 `무료`로 |
| 속성 띠 `텍스트에서 음성으로` | → **내 목소리로 읽기**(Chatterbox) |
| 대본 패널 | → 유진이 대본을 읽고 **장면마다 내 자산을 고름** ← **여기가 핵심** |

### 4.3 재사용을 최대화하는 자리

**대본 패널이 재사용 엔진이다.** 대본을 넣으면 유진이 장면을 나누고,
장면마다 **이미 가진 B-roll·음악·효과음**을 골라 채운다. 캡컷은 매번 사람이 찾는다.

이 흐름이 §2.1이 말한 "차별점은 자산이 아니라 고르는 일"의 구현이다.

## 5. 우리 시스템 최종 그림

### 5.1 첫 화면 (`/projects` → 캡컷 `/my-edit` 대응)

```
┌─사이드바 228px──┬──────────── 본문 ────────────┐
│ [+ 새로 만들기]  │  최근 프로젝트                 │
│ 🏠 홈           │  [카드][카드][카드]            │
│ ───────────    │   썸네일+길이 / 제목 / 메타      │
│ 내 자산          │   (카드에 버튼 없음)           │
│  내 B-roll      │                              │
│  내 목소리       │  유진 추천                     │
│  음악·효과음     │  (지금 만들 만한 것)            │
│ ───────────    │                              │
│ 프로젝트         │                              │
│  최근 프로젝트    │                              │
│  보관함          │                              │
└────────────────┴──────────────────────────────┘
```

- **`+ 새로 만들기` 하나.** 지금의 시작 경로 3개는 이 안의 선택으로 들어간다.
- 카드에서 `검토하기`·`계속 만들기`·`···` **제거**(캡컷처럼 눌러서 연다).
- `격자/줄/보관함` 토글 → 사이드바 항목으로.

### 5.2 편집기

왼쪽 세로 띠 **6항목**: 미디어 · 오디오 · 텍스트 · 캡션 · 대본 · 전환
오른쪽 속성 띠: 선택에 따라(영상=기본·배경·속도 / 글자=기본·내 목소리로 읽기·애니메이션)

### 5.3 내보내기

팝오버 2단계: `다운로드`(MP4) · `공유 링크` · `유튜브` · `CapCut 초안`

## 10. owner 결정 — **2026-09-04 확정됨**

세 가지 다 정해졌다. 기록: `decisions/2026-09-04-capcut-shell-with-my-assets.ko.md`

1. **`속도`는 캡컷과 동일하게.** 배속이 길이를 바꾼다.
   → **정정:** 엔진은 `set_segment_ripple_playback_rate`
   (`editing_session.py:611`)로 **이미 그렇게 동작한다.** `display_duration =
   source_duration / rate`로 길이를 바꾸고, 자막·자산 창을 같이 줄이고, 뒤
   장면들을 당긴다. 유진의 `set_scene_speed`도 이 함수로 이어지고
   (`:853`), 화면도 `RightDock.tsx:85`에서 이걸 부른다.
   **즉 새 엔진 기능이 아니라 대부분 화면 일이다.** 앞서 "동작도 맞춰야 한다"고
   크게 적은 것은 과대평가였다.

   바꿀 것: 이름(`장면 길이` → **`속도`**), 모양(단추 3개 → `속도 x` + `기간 s`
   연동 숫자칸), 허용 값 확대(지금 `{1.0, 1.5, 2.0}` 고정 —
   `editing_session.py:25`와 `composition_plan.py:23` **두 곳에 같은 집합이
   있으니 둘 다** 고친다. `MIN_SEGMENT_DURATION_SEC` 검사와 렌더 `atempo`
   범위(0.5~2.0)도 같이 본다), 속성 띠 `속도` 항목으로 이동.
2. **`내 자산` 구역 승인.** 내 B-roll / 내 목소리 / 음악·효과음.
3. **제품은 B-roll 브이로거용.** 자산 재사용이 제품의 중심이다.
   나중에 월 2~3만원 구독으로 판다 — **다만 결제·다중 사용자는 지금 범위 밖**
   (§6 승인 대상). 지금은 1인용으로 만들되 **되돌리기 비싼 결정만 피한다.**

**새 설계 판단 기준:** 어떤 화면이든 "이게 내 자산을 다시 쓰기 쉽게 하는가"를
먼저 묻는다. 아니면 우선순위가 낮다.
