## 리스크

- B~F는 유진 프롬프트를 길게 만든다 → 로컬 모델 응답 시간을 묶음마다 잰다(`lms ps`로 GPU 경합부터 확인).
- 의도가 늘수록 애매한 문장 오해가 늘 수 있다 → 되묻기 지침 유지, 묶음마다 거짓 긍정 시험.
- G4는 화면 배치 변경 — 결정 문서로 승인됨, 팔레트는 건드리지 않음.
