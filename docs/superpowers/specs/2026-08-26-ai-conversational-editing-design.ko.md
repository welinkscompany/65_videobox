# 자유 대화형 AI 편집·검토 적용 설계

## 목표

창작자가 자연어로 편집을 요청하면 유진이 현재 편집본을 기준으로 **검토 가능한 편집안**을 만들고, 창작자가 미리보기와 명시적 적용을 거쳐 반영할 수 있게 한다. 적용된 AI 편집과 수동 편집은 같은 최근 10단계 되돌리기·다시 실행 이력을 사용한다.

## 제품 원칙

- 자유 문장은 넓게 받되, 실제 저장 변경은 검증된 타입화 편집 동작만 사용한다.
- 유진은 파일·타임라인을 직접 바꾸지 않는다. `미리보기 → 적용`을 거쳐야 한다.
- 모호하거나 지원하지 않는 요청은 추측해 바꾸지 않고, 필요한 정보를 묻거나 가능한 대안을 제안한다.
- AI 적용은 기존 편집 세션, 현재성 확인, 미리보기, 내보내기 경로를 재사용한다.
- 기본 화면 문구에는 개발 용어를 쓰지 않는다. 사용자가 이해할 수 있는 `편집안`, `변경 내용`, `미리보기`, `적용`, `되돌리기`만 쓴다.
- 승인된 흰 바탕·주황 강조색·상단 경로와 단계 배치는 바꾸지 않는다.

## 사용자 흐름

1. 창작자가 오른쪽 `유진에게 요청하기`에 자연어 요청을 입력한다.
2. 유진은 대화 답변과 함께 다음 중 하나를 반환한다.
   - `편집안 준비`: 변경 대상, 변경 전후, 예상 길이 변화, 미리보기 가능 여부를 가진다.
   - `추가 질문`: 대상을 특정하거나 선택지를 고르게 한다.
   - `할 수 없음`: 현재 지원하지 않는 이유와 가능한 대안을 짧게 설명한다.
3. 대화 아래에는 편집안의 짧은 요약, `미리보기`, `편집안 열기`를 보인다. 이 단계는 저장하지 않는다.
4. `편집안 열기`는 변경 대상·영향·전후를 보여 주고, `적용`을 눌렀을 때만 기존 편집 명령 경로로 저장한다.
5. 저장 성공 후에는 같은 공통 이력에 한 단계로 기록한다.

## C 혼합형 화면

- 대화 패널: 대화, 마지막 편집안 요약, 미리보기, `편집안 열기`를 보인다.
- 편집안 트레이: 상세 변경 목록, 영향받는 장면, 길이 변화, 적용 전 확인을 보인다.
- 기존 상단의 되돌리기·다시 실행은 공통 편집 이력을 표시한다. 각 버튼은 최근 10단계 이내에서만 활성화한다.
- 화면 폭이나 긴 대화가 편집 작업판을 밀어내지 않도록, 상세 비교는 트레이에서만 연다.

## 지원 동작과 확장 경계

1차 적용 동작은 다음으로 제한한다.

- 장면 속도: 1배, 1.5배, 2배. 장면에 연결된 영상·기존 나레이션·자막 시간을 함께 조정한다.
- 장면 앞뒤 자르기, 제외·복원, 순서 변경.
- 자막 문구 수정.
- B-roll·음악·효과음의 넣기, 교체, 제거.

이 구조는 다음 동작을 같은 방식으로 추가할 수 있게 만든다: 화면 비율, 장면 전환, 자막 모양, 음량, 이미지·설명 카드, 구간 미리보기, 가로·세로 변형.

전문 색보정, 고급 마스크, 임의 키프레임, 멀티캠, 고급 모션그래픽, 캡컷 서버 전용 효과·필터·스티커는 현재 제품 경계 밖이다. AI가 이 요청을 받으면 실행하지 않고 지원 가능한 대안을 말한다.

새 음성 생성·개인 음성 복제는 이번 범위에 넣지 않는다. 속도·길이 변경 시 기존 음성·자막의 시간만 기존 편집 세션 경로로 맞춘다.

## 편집안 계약

편집안은 다음 필드를 가져야 한다.

- 사용자의 원래 요청과 이해한 요청 요약
- 현재 편집 세션을 가리키는 기준 정보
- 하나 이상의 타입화된 편집 동작
- 대상 장면 또는 자산의 안정 식별자
- 사람이 읽는 변경 전후 요약과 예상 길이 변화
- 미리보기 가능 여부와 추가 질문 또는 거절 사유

적용 전에는 기준 편집본이 여전히 현재인지 확인한다. 변경되었거나 대상이 사라졌으면 적용하지 않고 새 편집안을 받도록 안내한다. 한 편집안의 여러 동작은 모두 성공할 때만 하나의 수동 편집 이력으로 저장한다.

## 되돌리기·다시 실행

- 적용 성공한 AI 편집과 수동 편집은 동일한 이력을 쓴다.
- 되돌리기는 최대 최근 10단계, 다시 실행도 최대 최근 10단계로 제한한다.
- 되돌린 상태에서 새 편집을 저장하면 다시 실행 목록은 비운다.
- 편집안 만들기, 미리보기, 추가 질문, 거절, 적용 실패는 이력을 바꾸지 않는다.
- 적용 실패는 기존 편집본을 보존하고, 사용자가 다시 시도할 수 있는 이유를 보여 준다.

## 꼬리 질문 추천

유진은 마지막 대화, 현재 선택한 장면, 열려 있는 편집안을 바탕으로 **최대 세 개**의 다음 질문을 제안한다.

- 예: 속도 편집안 뒤에는 `원래 속도로 되돌려 볼까요?`, `앞뒤 장면도 같은 속도로 맞출까요?`, `이 구간만 미리 볼까요?`
- 예: 음악 교체안 뒤에는 `더 차분한 음악으로 찾아볼까요?`, `이 장면부터만 바꿀까요?`, `효과음도 함께 넣을까요?`
- 추천을 누르면 입력칸에 문장만 채운다. 자동 전송·자동 적용은 하지 않는다.
- 질문이 맞지 않거나 정보가 부족하면 추천을 숨긴다. 빈 추천 영역을 만들지 않는다.

## AI 이해도 평가

지원 동작마다 한국어 표현이 다른 명령 표본을 만든다. 검증은 실제 로컬 AI 응답을 편집안 스키마로 검증하고 아래를 측정한다.

- 요청한 동작 종류와 대상 장면을 맞췄는가.
- 속도·자르기 길이 등 수치를 정확히 보존했는가.
- 모호한 요청에서 적용안을 만들지 않고 질문했는가.
- 범위 밖·위험 요청에서 저장 변경 없이 거절 또는 대안을 제시했는가.
- 만든 편집안이 실제 적용·되돌리기·다시 실행·미리보기·MP4/선택적 CapCut 출력 경로를 통과하는가.

모델의 대화 품질은 고정 문장 시험만으로 완료 판정하지 않는다. 대표님 프로젝트에서의 화면 확인과 결과 영상 검토는 별도 사람 수용 확인으로 남긴다.

## 재사용·제외 판단

- 재사용: 기존 편집 세션의 변경 명령·되돌리기·다시 실행, `materialize_editing_session_timeline`, 편집기 미리보기, 미디어 제안·물질화, 현재성 확인.
- 선별 확장: 현재 유진 대화 응답과 참조 해석을 타입화 편집안·질문 추천으로 연결한다.
- 제외: 새 브라우저 편집 엔진, 자동 적용, 외부 AI 연결, CapCut 서버 자산 탭, 승인된 팔레트·배치 변경.

## 완료 기준

- 창작자가 서로 다른 자연어 표현으로 지원 동작을 요청해 편집안·미리보기·명시적 적용까지 진행할 수 있다.
- AI 적용과 수동 변경이 최근 10단계 되돌리기·다시 실행에서 같은 방식으로 동작한다.
- 꼬리 질문은 최대 세 개만 나타나며, 클릭해도 자동 전송·자동 적용하지 않는다.
- 모호함·현재성 불일치·범위 밖 요청이 기존 편집본을 바꾸지 않는다.
- 백엔드·웹 시험, 타입 검사, 실제 로컬 컨테이너와 브라우저의 대표 경로 검증을 구분해 남긴다.
