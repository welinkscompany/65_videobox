# 인계 — 대표님 목소리로 더빙까지 (2026-09-03)

## 한 줄

**동영상 번역기가 끝까지 돈다.** 자막을 옮기고, 그 자막을 **대표님 목소리로**
읽혀 내레이션을 바꾸고, 완성본 mp4까지 나온다. 실물로 확인했다.

## 지금 상태 (실측)

| | 상태 |
|---|---|
| 자막 번역 | 영어·일본어·중국어. 원본은 지우지 않고 나란히 쌓는다 |
| 목소리 더빙 | **대표님 목소리로 5/5 장면** 성공, 완성본 `export_014` |
| 기본 엔진 | `host_bridge` → chatterbox(**MIT, 상업 이용 가능**) |
| 목소리 샘플 | `asset_955ed1a13781` (바탕화면 유튜브 영상 90초 지점 20초) |

## 쓰는 법

```
pwsh -File scripts/start-voice.ps1        # 목소리 프로그램을 켠다(한 줄)
```
깔려 있는 것 중 나은 것(chatterbox → XTTS)을 알아서 고르고 라이선스를 찍는다.
안 켜면 더빙이 **"목소리 프로그램을 켜 주세요"라고 말하고 멈춘다** — 조용히
기계 목소리로 대신 읽지 않는다.

## 이번에 고친 것 — 전부 실물로 재서 찾았다

1. **세션에 걸어도 완성본이 안 바뀌었다.** 렌더까지 성공했는데 이전 파일과
   **바이트까지 같았다.** 내레이션을 갈아 끼우는 것은 타임라인이라 부분
   재생성을 지나야 했다.
2. **더빙하면 완성본을 아예 못 만들었다.** 출력 화면이 "편집 화면에서 준비해
   주세요"라는데 편집 화면에 가도 같은 말이었다. 부분 재생성이 타임라인을
   만들고 **만들었다는 기록을 안 남겨서**였다.
3. **영어 자막을 고치면 한국어 원본이 사라졌다.** 화면엔 영어가 보이는데
   저장은 원본 자리로 갔다. 고친 영어는 반영도 안 됐다.
4. **긴 영상에서는 더빙이 끊긴다.** 장면당 13초 × nginx 330초 = **23장면**.
   대표님 영상은 백 장면이 넘는다. 유튜브 학습과 같은 방식으로 비동기로 바꿨고
   `5개 장면 중 3개 했어요`로 진행을 보여 준다.
5. 짧은 말을 늘리려던 것이 틀렸다 → **뒤를 조용히 채운다**(1/5 → 5/5).
6. 스스로 리뷰해서 여섯 건(무한 재요청, 한 장면 실패가 전체를 버림 등).

## 재 본 것과 안 잰 것

- 잰 것: 더빙 장면당 13초, 번역 5장면 5초, 완성본 md5 변화, 타임라인 내레이션
  경로, 진행 1/5→5/5, 요청 응답 0초
- **안 잰 것: 목소리가 대표님처럼 들리는가.** 이건 대표님만 판단할 수 있다.
  안 닮았으면 샘플 구간을 바꾸거나 더 길게 뽑는다.
- 안 잰 것: **백 장면짜리 실제 영상으로 끝까지** 돌려 본 적은 없다.
  다섯 장면짜리로만 확인했다.
