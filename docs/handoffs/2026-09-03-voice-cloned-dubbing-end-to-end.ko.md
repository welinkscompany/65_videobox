# 인계 — 대표님 목소리로 더빙까지 (2026-09-03)

앞 인계: `2026-09-02-caption-translation-and-inspector-tabs.ko.md`

## 한 줄

**동영상 번역기가 끝까지 돈다.** 자막을 옮기고, 그 자막을 **대표님 목소리로**
읽혀 내레이션을 바꾸고, 완성본 mp4까지 나온다. 실물로 확인했다.

## 지금 상태 (실측)

| | 상태 |
|---|---|
| 자막 번역 | 영어·일본어·중국어. 원본은 지우지 않고 나란히 쌓는다 |
| 목소리 더빙 | **대표님 목소리로 5/5 장면** 성공, 완성본 `export_014` |
| 기본 엔진 | `host_bridge` → chatterbox(**MIT, 상업 이용 가능**) |
| 목소리 샘플 | `asset_955ed1a13781` (바탕화면 유튜브 영상 90초 지점 20초) |

## 쓰는 법

```
pwsh -File scripts/start-voice.ps1        # 목소리 프로그램을 켠다(한 줄)
```
깔려 있는 것 중 나은 것(chatterbox → XTTS)을 알아서 고르고 라이선스를 찍는다.
안 켜면 더빙이 **"목소리 프로그램을 켜 주세요"라고 말하고 멈춘다** — 조용히
기계 목소리로 대신 읽지 않는다.

## 이번에 고친 것 — 전부 실물로 재서 찾았다

1. **세션에 걸어도 완성본이 안 바뀌었다.** 렌더까지 성공했는데 이전 파일과
   **바이트까지 같았다.** 내레이션을 갈아 끼우는 것은 타임라인이라 부분
   재생성을 지나야 했다.
2. **더빙하면 완성본을 아예 못 만들었다.** 출력 화면이 "편집 화면에서 준비해
   주세요"라는데 편집 화면에 가도 같은 말이었다. 부분 재생성이 타임라인을
   만들고 **만들었다는 기록을 안 남겨서**였다.
3. **영어 자막을 고치면 한국어 원본이 사라졌다.** 화면엔 영어가 보이는데
   저장은 원본 자리로 갔다. 고친 영어는 반영도 안 됐다.
4. **긴 영상에서는 더빙이 끊긴다.** 장면당 13초 × nginx 330초 = **23장면**.
   대표님 영상은 백 장면이 넘는다. 유튜브 학습과 같은 방식으로 비동기로 바꿨고
   `5개 장면 중 3개 했어요`로 진행을 보여 준다.
5. 짧은 말을 늘리려던 것이 틀렸다 → **뒤를 조용히 채운다**(1/5 → 5/5).
6. 스스로 리뷰해서 여섯 건(무한 재요청, 한 장면 실패가 전체를 버림 등).

## 재 본 것과 안 잰 것

- 잰 것: 더빙 장면당 13초, 번역 5장면 5초, 완성본 md5 변화, 타임라인 내레이션
  경로, 진행 1/5→5/5, 요청 응답 0초
- **안 잰 것: 목소리가 대표님처럼 들리는가.** 이건 대표님만 판단할 수 있다.
  안 닮았으면 샘플 구간을 바꾸거나 더 길게 뽑는다.
- **실제 규모(243장면)로 잰 것**: 번역 21묶음 전부 제자리, 유진 프롬프트 상한,
  더빙 프록시 벽(52분 > 330초), 화면 폴링 한도(35분 < 52분). 넷 다 고쳤다.
- **화면에서 확인한 것**: 더빙 단추 → `목소리를 만들고 있어요. 5개 장면 중
  4개 했어요.` → `5개 장면의 목소리를 바꿨어요.`까지 실제 화면에서 봤다.
- **243장면 재생성은 쟀다 -- 2.4초.** 더빙이 끝날 때마다 지나는 부분 재생성이
  실제 규모를 견딘다(`tests/test_dubbing_scale.py`). 목소리는 안 만들고 소리
  파일 하나를 243장면이 같이 쓰게 해서 **52분짜리 위험을 3초에** 쟀다.
- 안 잰 것: 243번을 **실제로 합성**해 완성본까지 낸 적은 없다(52분). 구조는
  다 쟀고 남은 것은 "합성을 243번 반복해도 되는가"라는 약한 걱정뿐이라
  값어치가 없다고 판단했다.

## 남은 것

- **유진이 번역문을 다듬는 길이 없다.** 지금 유진의 자막 고치기는 한국어
  원본을 고친다(유진이 한국어를 보고 말하므로 맞다). 그런데 영어를 보고 있을
  때 "이 자막 짧게 줄여 줘"라고 하면 **바뀐 것이 완성본에 안 보인다.**
  → 다음 슬라이스 후보 1순위.
- 자막 타이밍 재조정(번역이 장면보다 길 때) — 지금은 못 넣고 말해 준다.
- 캡컷 대조 안 끝난 화면 넷, Tauri Smart App Control — owner 몫.
- `기능 섞어 쓰기 시험`(project-318cc020)에 검증 흔적이 쌓여 있다. 지워도 된다.

## 목소리 관리 (2026-09-03 추가, owner 요청)

owner: "버튼을 눌러서 녹음해서 새로운 버전으로 만들수 있게. 다른 여러개
유튜브를 만들수도 있어. 관리할수 있게."

`자료실 > 내 목소리`에서:
- **녹음 단추** — 마이크로 바로 녹음해 저장한다(파일을 따로 만들 필요 없다)
- **길이 표시** — `12초 — 15초는 넘겨 주세요. 짧으면 목소리가 잘 안 닮아요.`
  몇 초 읽었는지 안 보이면 짧아서 안 닮은 것을 모르고 포기한다
- **이름 붙이기 · 지우기** — 채널마다 목소리가 다르면 이름이 없으면 못 고른다

**목소리 자산만** 이름을 바꾸고 지운다 -- id를 잘못 넘겨 내레이션이나 촬영본이
사라지면 되돌릴 길이 없다. 저장 쪽은 이미 있던 `update_asset_metadata`/
`delete_asset`에 화면을 연결했을 뿐이다.
