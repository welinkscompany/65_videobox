# VideoBox 인계 — 자산 검색 체계와 정리 (2026-08-09)

## 이 세션이 실제로 바꾼 것

### 1. 자산 검색 체계 (새로 만듦)

음악·효과음·촬영본을 한 문으로 찾는다. 자세한 것은 `CLAUDE.md` §2.2.

- `packages/core-engine/.../audio_descriptors.py` — ffmpeg + numpy로 세기·밝기·빠르기 측정
- `packages/core-engine/.../library_audio_indexer.py` — 음악·효과음 색인
- `packages/core-engine/.../library_footage_indexer.py` — 촬영본 색인
- `MediaLibraryStore` — `library_audio_descriptors`, `footage_index` 두 테이블
- `POST /api/media-library/search`

실제 확인: 팩 130개 + 촬영본 9개 전부 색인됐고, 네 가지 질의가 모두 맞는 결과를 1등으로 냈다.

**주의할 함정 두 개.**

설명 문장이 획일적이면 벡터가 뭉쳐서 검색이 사실상 무작위가 된다. 처음 만든 고정 틀에서
"신나고 빠른 음악"에 보통/보통 곡이 1등이었고 2등과 0.002 차였다.

모델은 시키지 않으면 영어로 답한다. 언어가 어긋나면 점수가 0.52~0.59로 떨어진다
(우리말끼리는 0.63~0.70).

### 2. 음악 추천이 실제로 곡을 고른다

전에는 `selected_asset_id: None`으로 영어 분위기 문장만 돌려줬다. 고르는 규칙이
`"team"`, `"meeting"` 같은 영어 단어를 한국어 내레이션에서 찾는 것이라 사실상 항상
같은 기본값이었다.

이제 라이브러리 의미검색으로 실제 곡을 고른다. 아직 프로젝트에 없으면
`needs_import`를 함께 보내고 `selected_asset_id`는 비운다 — 없는 자산을 있는 척하지
않는다.

### 3. 유휴 부하 (측정으로 확인)

| | 전 | 후 |
|---|---|---|
| workspace CPU | 32.6% | 2.8% |
| Postgres CPU | 41.1% | 6.1% |
| DB 트랜잭션 | 180건/초 | 13건/초 |

원인은 유지보수 루프의 0.05초 간격이었다. **파일 I/O가 아니었다** — 드롭 폴더 감시의
전체 해시를 먼저 의심했지만 고쳐도 CPU가 그대로였다. postgres가 41%였다는 게 단서였다.

### 4. 그 밖에 고친 것

- 재시작이 작업을 `running`으로 굳히고 되살릴 수 없던 문제 (실제로 15시간 굳어 있었다)
- 오버레이 폰트 — 오타(`VIDEBOX_`), Windows 경로 기본값, 한글 폰트 부재 세 겹
- 화면의 영어 원값들 (`stale`, `BGM`, `SFX`, `subtitle render`, `succeeded`, 트랙 역할)
- 승인 색을 안 쓰던 미리보기 무대·선택 필터
- CSS 규칙이 없던 화면 일곱 개
- 유진 대화 삭제 기능 (28건이 쌓였는데 지울 방법이 없었다)
- `request`가 204를 JSON으로 읽어 성공한 삭제를 실패로 보이게 하던 버그

## 정리한 것

- `artifacts/` 1.4G → 390M. 판단 기준은 `CLAUDE.md` §5에 있다.
- `apps/web/src/lib/formatters.tsx` 562줄 → 30줄. export 39개 중 화면이 쓰는 것은 둘뿐이었다.
- `services/worker/` 삭제 — `__init__.py` 한 줄짜리 placeholder였고 어디에도 등록돼 있지 않았다.
- `prune_stale_media_analysis_cache`를 실제로 연결. 정의와 테스트만 있고 부르는 곳이 없어
  `media_analysis_cache`와 `media_embeddings`가 계속 늘고 있었다.

### 이 구간에서 배운 것

- 호출부에 로거를 달아도 **설정이 없으면 최후 수단 핸들러가 메시지만 찍는다.**
  컨테이너에서 `root handlers: []`를 보고서야 알았다.
- **화면에서 못 찾은 것을 결함으로 보고할 뻔했다.** 자막 스타일은 네 겹(창 너비
  1600, 오른쪽 독, 편집 항목 펼치기, `편집 대상`을 `연결 자막`으로)을 지나면
  정상적으로 열린다.
- 무거운 작업을 **한꺼번에 거는 것**이 실패 원인이 된다. 재분석 네 건을 동시에
  걸었더니 전부 타임아웃했다. 색인기들이 8개·2개씩 끊는 이유가 이것이다.
