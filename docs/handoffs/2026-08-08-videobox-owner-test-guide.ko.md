# 2026-08-08 owner 테스트 안내 — 지금 상태와 확인 방법

전날 새벽까지 브라우저로 전 구간을 직접 클릭해 점검했다. 이 문서는 owner가 바로
테스트할 수 있도록 **되는 것과 안 되는 것**을 구분해 적는다.

## 실행

```powershell
.\scripts\owner-ready.ps1 -Mode Start
```

컨테이너를 쓰지 않고 직접 띄우려면 **worktree에서** 두 개를 실행한다
(`preview_start`는 main 체크아웃을 띄우므로 쓰지 않는다).

```
.venv/Scripts/python.exe scripts/run_api.py
npm --prefix apps/web run dev -- --port 5199 --strictPort
```

주의: 데이터 경로가 길면 Windows 경로 길이 제한에 걸려 초안 생성이 실패한다
(`staging/...json` 없음 오류). 기본 경로는 짧으므로 문제없다.

## 유진 기억(Mem0) — 지금은 꺼져 있다

**내일 테스트는 이 상태 그대로 하는 것을 권한다.** 로컬 기억으로 동작한다.

준비는 끝나 있다. owner 승인(2026-08-08)에 따라 실행기에 스위치를 넣었고,
필요한 값은 `.env.container`에 이미 다 있다. 켜고 싶을 때만 이렇게 한다.

```powershell
.\scripts\owner-ready.ps1 -Mode Start -WithYujinMemory
```

**켜기 전에 알아야 할 것 두 가지.**

1. **승인한 기억 문구가 외부로 나간다.** 나가는 것은 승인 저장한 기억 텍스트
   (280자 이내)와 검색 질의뿐이다. **영상·자산·대본 파일, 프로젝트 이름은 나가지 않는다.**
   대화 전체가 자동으로 올라가지도 않는다 — owner가 승인한 항목만 간다
2. **조회 폴백이 없다.** 게이트웨이가 죽으면 유진이 과거 기억을 참조하지 못한다.
   기억이 지워지는 건 아니고(로컬 기록은 그대로다) 꺼내 줄 검색이 없는 것이다.
   대화 자체는 로컬 모델로 계속된다

켠 뒤에는 `scripts/smoke-hermes-yujin-mem0.ps1`로 확인할 수 있다.
근거와 경계는 `docs/development-fast-path.ko.md` `§10.14` 조항 2-A에 있다.

**왜 켜는가.** 유진의 로컬 기억이 **한 번에 5개·각 280자**로 제한돼 있다
(`yujin_memory_service.py:20`). 대화가 길어지면 실제로 부족하다.

## 확인된 것 (브라우저에서 실제로 클릭해 검증)

| 화면 | 상태 |
|---|---|
| 홈 | 열림. 카드 3개는 이동 버튼이며 상태 표시는 고정 문구다 |
| 자산 보관함 | 열림. **따로 모아둔 영상 가져오기**로 촬영본 반입 |
| 새 영상 만들기 | 열림. 대본 → 질문 → 요약 승인 → 초안 준비 → 초안 만들기 |
| 편집 작업판 | 열림. 트랙·타임라인·자막·B-roll이 실제 내용으로 표시 |
| 검토 | 열림. **검토 승인** / **검토 다시 열기** 동작 |
| 출력 | 열림. **자막·완성본·CapCut 초안** 세 버튼 모두 활성 |

**실물 확인.** 출력 화면에서 `완성본 만들기`를 눌러 실제 mp4가 만들어지는 것을 확인했다.

```
exports/final_render/export_001/output.mp4
h264 1920x1080 10.0초
```

## 권장 테스트 순서

1. **자산** → `따로 모아둔 영상 가져오기`에서 촬영본 몇 개를 프로젝트로 반입
2. **새 영상 만들기** → 대본 붙여넣기 → 질문 넘기고 요약 승인
   - **숏폼을 만들 거면 `숏폼(세로)으로 만들기`를 체크한 뒤** 초안을 만든다
3. **편집** → 장면·자막·B-roll 확인, 필요하면 구간 조정
4. **검토** → `검토 승인`
5. **출력** → `자막 만들기` → `완성본 만들기`

## 아직 안 되는 것 / 확인 안 된 것

- **내 목소리 TTS** — 샘플만 만들어 뒀다. 들어보고 쓸지 정해야 한다:
  `20_project\65_videobox-project\tts-sample\chatterbox-korean-sample.wav`
  (기본 목소리로 만든 것이며, 본인 목소리 복제는 10초짜리 참조 녹음이 필요하다)
- **마이크 직접 녹음** — 구현은 있으나 **실제 마이크로 전사까지 간 기록이 없다.**
  owner의 1순위 경로이므로 이번 테스트에서 꼭 한 번 해볼 것
- **CapCut 초안** — 버튼은 활성이지만 실제 CapCut Desktop 연동은 확인하지 않았다
- **홈 카드 상태 표시** — 고정 문구다. 실제 상태를 보여주려면 홈에서 데이터를
  불러오는 설계 변경이 필요하고, 그건 owner 결정 사항이다 (Task 35)
- **세로 출력 실렌더** — 코드와 테스트로는 확인했으나 실제 세로 mp4를 만들어보지 않았다
