# VideoBox 2026-08-25 캡컷 비교 잔여 작업 인계

**대체됨:** `2026-08-25-videobox-navigation-compact-controls-handoff.ko.md`

## 실제로 한 일

- B-roll 편집 항목에 `화면 안에 맞추기`와 `화면 채우기`를 추가하고, 화면 값이 `EditorControls`·명령 포트·API payload·렌더 경로까지 보존되도록 연결했습니다.
- 선택한 장면의 `선택 구간 미리보기`를 추가했습니다. 선택 범위를 read-model로 먼저 확인한 뒤 같은 `start_sec`·`end_sec`로 exact preview를 요청합니다.
- 자막 스타일 저장 전에 영향 범위를 확인하는 preflight를 추가했습니다. 확인 중 다른 저장이 끼어들거나 중복 저장되지 않도록 막고, 실패 시 화면에 안내합니다.
- 오른쪽 편집창에 `영상·소리`, `자막`, `화면 요소` 바로가기를 추가했습니다. 접근성상 실제 탭이 아니라 상태가 읽히는 버튼 그룹으로 구현했습니다.
- 새 동작과 경합·실패 경로에 웹 시험을 추가했고, 계획서는 `docs/superpowers/plans/2026-08-25-capcut-gap-followups.md`에 남겼습니다.

## 검증했지만 못 끝낸 것

- 화면을 눈으로 비교하는 P0-1은 원래 인계대로 목요일에 대표님이 확인해야 하므로 완료로 표시하지 않았습니다.
- 출력 해상도·프레임률·코덱 선택과 자동 자막 생성은 대표 결정 전 범위라 구현하지 않았습니다.
- 실제 외부 게시·업로드나 provider/live 환경 검증은 하지 않았습니다.

## 검증 근거

- 웹 전체: `apps/web`에서 `npx vitest run` — 96개 파일, 1,273개 통과.
- 웹 타입: `apps/web`에서 `npx tsc --noEmit` — 통과.
- 백엔드 전체: `.venv\\Scripts\\python.exe -m pytest` — 4,046 통과 / 56 건너뜀.
- 컨테이너: `./scripts/owner-ready.ps1 -Mode Start -Rebuild -WithYujinMemory` — 재빌드·기동 PASS, `http://127.0.0.1:5173/health` 200.
- 실제 브라우저: B-roll을 `화면 채우기`로 저장하고 새로고침 후 다시 `화면 채우기`로 읽히는 것을 확인한 뒤 원래 값인 `화면 안에 맞추기`로 복원했습니다. 선택 구간 미리보기, 바로가기, B-roll 화면 맞춤 문구도 DOM에서 확인했습니다.
- 코드리뷰: 별도 리뷰 에이전트가 최신 커밋을 재검토했고 추가 P1/P2 없음으로 승인했습니다.

## 목요일에 화면으로 확인해야 할 것

- 실제 대표님 영상에서 `화면 안에 맞추기`와 `화면 채우기`가 의도한 구도 차이로 보이는지 확인합니다.
- 선택 구간 미리보기가 타임라인 전체를 바꾸지 않고 선택 장면만 재생하는지 확인합니다.
- 자막 스타일을 저장할 때 영향 장면 안내와 저장 완료 문구가 이해되는지 확인합니다.
- 오른쪽 편집창의 세 바로가기가 자막·화면 요소를 찾는 시간을 줄이는지 확인합니다.
- 기존 승인 팔레트와 패널 배치가 달라지지 않았는지 확인합니다.
