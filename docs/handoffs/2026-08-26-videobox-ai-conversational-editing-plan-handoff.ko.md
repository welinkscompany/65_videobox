# VideoBox 2026-08-26 자유 대화형 AI 편집 설계·계획 인계

## 실제로 한 일

- 대표님이 승인한 방향을 `자유 대화 → 타입화된 편집안 → 미리보기 → 명시적 적용 → 공통 이력`으로 고정했습니다. AI가 자유 문장을 바로 저장 변경으로 실행하는 방식은 채택하지 않았습니다.
- C 혼합형 화면을 선택했습니다. 대화 아래에는 짧은 편집안 요약·미리보기·상세 열기를 두고, 상세 비교·적용은 별도 트레이에서 합니다.
- 꼬리 질문은 마지막 대화·선택 장면·열려 있는 편집안에 따라 최대 세 개만 추천하며, 클릭해도 입력칸만 채우고 자동 전송·적용하지 않는 것으로 확정했습니다.
- 기존 편집 세션의 되돌리기·다시 실행은 이미 10개의 undoable 변경을 유지합니다. 새로 이력을 만들지 않고 AI 적용도 같은 이력에 한 번의 변경으로 기록하도록 계획했습니다.
- 설계 문서와 상세 구현 계획을 작성해 원격 브랜치에 푸시했습니다.

## 검증한 것

- 설계·계획 문서의 `TODO`·`TBD`·빈 구현 지시 문구를 검색했고 발견되지 않았습니다.
- 두 문서 커밋 전 `git diff --check`를 통과했습니다. 계획서의 줄 끝 공백은 발견 즉시 같은 커밋에서 제거했습니다.
- 현재 브랜치는 `codex/videobox-container-compatibility`이며, 최신 HEAD는 `17a89457`입니다.
- 현재 로컬 컨테이너의 `http://127.0.0.1:5173/health`는 앞선 점검에서 `{"status":"ok","store":"postgres"}`를 반환했습니다. 이 인계 작성 중에는 재빌드하지 않았습니다.

## 구현하지 않은 것

- 상세 구현 계획의 Task 1~7은 **아직 한 줄도 구현하지 않았습니다**. 타입화 편집안 모델, 로컬 AI 구조화 응답, API 생성·현재성 검사·원자 적용, UI 트레이, 꼬리 질문 버튼, AI 명령 평가, 브라우저 역방향 검증 모두 다음 세션의 작업입니다.
- 실제 로컬 AI가 다양한 한국어 편집 명령을 제대로 이해하는지는 아직 측정하지 않았습니다. 현재 프로젝트 `20260817`에는 편집 세션이 없어 실제 요청을 보내지 않았습니다.
- 외부 provider, 게시·업로드, 네트워크 경계, 승인된 팔레트·배치는 변경하지 않았습니다.

## 보호 상태와 주의점

- `output/`은 사용자 보존 미추적 산출물입니다. 삭제·스테이지·커밋하지 마십시오.
- `.superpowers/`는 gitignore 대상입니다. 이번 설계 논의용 브라우저 목업이 남아 있어도 제품 코드·커밋 범위가 아닙니다.
- 컨테이너는 직접 `docker compose`로 다루지 말고 `./scripts/owner-ready.ps1 -Mode Start -Rebuild -WithYujinMemory`만 사용합니다.
- 백엔드 시험은 `.venv/Scripts/python.exe -m pytest`, 웹 시험은 `apps/web`에서 `npx vitest run`, `npx tsc --noEmit`을 사용합니다.
