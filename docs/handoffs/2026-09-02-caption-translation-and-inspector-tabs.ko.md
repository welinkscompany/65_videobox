## 이번에 한 것

### 1. 동영상 번역기 1단계 — 자막 번역 (새로 만듦)

`docs/decisions/2026-09-02-video-translator-step-one-captions.ko.md`가 결정 기록.

편집기 속성 패널 `자막 스타일` 바로 아래에 **`자막 언어`** 절이 생겼다.
`원본 · 영어 · 일본어 · 중국어` 네 칸이고, 아직 안 옮긴 언어는 `영어로 번역`으로,
이미 옮긴 언어는 `영어`로 뜬다. 누르면 로컬 모델이 옮기고 바로 그 언어가
완성본에 실린다.

**원본은 지우지 않는다.** `segment["caption_translations"]`에 언어별로 쌓이고,
`session["caption_language"]`가 어느 쪽을 낼지 고른다. `원본`으로 되돌려도 번역은
남아 있다.

닿는 자리(새 필드를 더할 때 여기를 다 지나야 한다):

| 층 | 파일 |
|---|---|
| 읽는 곳(하나) | `composition_plan.py` `materialize_editing_session_timeline` |
| 저장·읽기 | `caption_translation.py` |
| 모델 호출 | `caption_translation_service.py` |
| 저장 화이트리스트 | `local_project_store.py` `_write_editing_session` |
| API | `routers/editing_session.py` (POST `caption-translations`, PATCH `caption-language`) |
| 화면 | `InspectorControls.tsx` → `RightDock` → `editorWorkbenchReadOnlyAdapters` |
| 상태 | `editorSnapshot.ts` (`captionLanguage`, `translatedLanguages`) |

### 2. 동영상 번역기 2단계 — 목소리 더빙 (새로 만듦)

`docs/decisions/2026-09-02-video-translator-step-two-dubbing.ko.md`가 결정 기록.

`자막 언어` 바로 아래에 **`목소리 더빙`** 절이 생겼다. **옮긴 언어만** 단추로
뜬다 -- 옮겨 둔 자막이 곧 대본이라 번역 안 한 언어는 읽을 것이 없다.

**엔진이 둘이다.** `espeak`(이미지에 포함, 기본값)는 설치 없이 오늘 되지만
**기계 목소리**다. 창작자 목소리로 더빙하려면 `chatterbox`를 설치하고
`VIDEOBOX_TTS_ENGINE`만 바꾼다 -- 코드는 그대로다.

길이는 **긴 말만 빠르게(1.25배까지), 짧은 말은 뒤를 조용히** 채운다.
못 맞춘 장면은 원래 목소리를 두고 화면에 사정을 말한다.

### 3. 목소리 복제는 호스트에서 부른다 (owner 승인)

`docs/decisions/2026-09-02-host-voice-bridge.ko.md`가 결정 기록.

**목소리 복제 엔진은 이미 이 컴퓨터에 있었다** — 저장소 루트 `.venv`에
XTTS 0.27.5 + torch 2.8.0 + 모델 1.8GB. (앞서 "설치가 필요하다"고 한 것은
worktree의 `.venv`만 보고 틀린 판단이었다.)

컨테이너에 3GB를 넣지 않고, 그림 생성이 ComfyUI를 부르는 것과 **같은 방식**으로
호스트에서 부른다.

```
COQUI_TOS_AGREED=1 <저장소루트>/.venv/Scripts/python.exe scripts/host_tts_service.py
```
그리고 `VIDEOBOX_TTS_ENGINE=host_bridge`.

실측: 제품 경로로 5장면 중 **3장면이 복제 목소리로 더빙**(24000Hz = XTTS),
나머지 둘은 1.25배 규칙에 걸려 정직하게 거절. **복제 엔진은 espeak보다 느리게
말해서**(같은 문장 3.58초 vs 6.30초) 거절이 늘어난다.

**엔진 둘 다 실측했다.**

| 엔진 | 띄우는 파이썬 | 라이선스 | 5장면 중 |
|---|---|---|---|
| `local_xtts` | 루트 `.venv` | 비상업용 | **3장면** |
| `chatterbox` | 루트 `.venv-chatterbox` | **MIT** | **5장면** |

chatterbox가 더 빠르게 말해서 길이 규칙에 덜 걸린다. **둘은 한 venv에 못
넣는다**(chatterbox가 torch를 2.6으로 내려 XTTS를 깨뜨린다) — 그래서 환경을
나눴고, 다리는 어느 환경에서 뜨든 상관하지 않는다.

chatterbox 설치에 함정이 하나 있다: `setuptools<81`을 같이 깔아야 한다.
워터마커(`perth`)가 `pkg_resources`를 부르는데 setuptools 81부터 빠졌고,
`perth`가 그 실패를 삼켜 클래스를 `None`으로 둔다 → 터질 때
**`'NoneType' object is not callable`**이라는 엉뚱한 말이 나온다.

**남은 것**: 호스트 서비스 자동 시작 없음(손으로 띄운다),
**대표님 목소리 샘플 없음**(유튜브 주소를 주시면 그 자리에서 가져온다).

## 실제로 재 본 것

- 로컬 모델이 5개 장면을 **자막 길이의 영어**로 옮겼다(실제 문장 확인)
- 화면 버튼이 `영어로 번역` → `영어`(눌림)로 바뀌고 **새로고침 뒤에도 유지**
- SRT 내려받기 전부 영어
- **완성본 mp4에 영어 자막이 구워졌다** — 2초·22초 프레임을 실제로 봤다
- `원본`으로 되돌리니 SRT가 다시 한국어, 영어 번역은 안 지워짐

## 더빙에서 실측으로 두 번 고쳤다

1. **짧은 말을 늘리려던 것이 틀렸다.** 다섯 장면 중 넷이 거절됐다 -- 영어가
   한국어 장면보다 짧은 것은 보통이고, 3.6초를 5초로 늘리면 0.72배가 된다.
   **말이 끝나면 조용해지면 된다.** 고친 뒤 1/5 → 5/5.
2. **세션에 걸어 두는 것만으로는 완성본이 안 바뀌었다.** 렌더까지 성공했는데
   완성본이 이전 파일과 **바이트까지 같았다**(md5 동일). 내레이션을 갈아 끼우는
   것은 타임라인이고, 세션의 선택이 거기 닿으려면 **부분 재생성**을 지나야 한다.
   그때 통과하던 시험들은 세션만 봤다 -- 재생성이 도는지 보는 시험을 넣었다.

## 만들면서 걸린 함정 셋 (다음 사람이 또 밟는다)

1. **장면 식별자에 콜론이 있다**(`timeline_001:001`). `식별자: 자막` 꼴로
   모델에 보내면 되받은 줄을 가를 수 없다. 번호만 보내고 되돌리는 일은 우리가 한다.
2. **저장 화이트리스트가 두 겹**이다. 세션에 새 칸을 더하면
   `_write_editing_session`의 목록에도 넣어야 한다. 안 넣으면 조용히 사라진다.
3. **`except Exception`이 내 실수를 삼켰다.** 프롬프트 만들다 난 NameError가
   "모델이 바빴다"로 둔갑해 번역이 빈 채 200이 나갔다. 좁혀 두었다.
4. **빈 칸이라도 늘 실으면 응답 모양이 바뀐다.** `caption_translations`를 모든
   장면에 `{}`로 실었더니 번역을 한 번도 안 쓴 프로젝트의 응답까지 달라졌고,
   저장 파일과 응답을 그대로 맞대는 창작 흐름 점검이 그걸 잡았다
   (`session_file_api_mismatch`). `exclude_if`로 안 쓰면 빼도록 맞췄다 --
   **이 넷은 전부 전체 pytest가 잡았다. 부분 실행으로는 안 나왔다.**

  "짧게 옮기라"는 지시로 완화했을 뿐 없앤 것이 아니다. 넘치는 사례가 나오면 연다.
- **번역문 직접 고치기** — 지금은 다시 번역하거나 원본으로 되돌리는 두 길뿐

## 스스로 리뷰해서 고친 여섯 (2026-09-02)

만든 것을 다시 읽어 고쳤다. **큰 둘은 시험이 못 잡고 있었다.**

1. **목소리 목록을 끝없이 다시 읽었다.** effect가 읽는 함수의 정체성에
   의존했는데 그 함수는 매 렌더마다 새로 만들어진다(만드는 자리가 early
   return 아래라 memo를 못 쓴다). → 함수는 ref로 들고 의존성을 값으로 바꿨다.
   처음엔 `useCallback`으로 고치려다 **프런트 147건을 깨뜨렸다** — 그 자리는
   hook을 못 쓰는 자리다.
2. **한 장면이 죽으면 더빙 전체가 날아갔다.** 장면당 20초가 넘는 작업이라
   스무 장면 중 열여덟째가 실패하면 몇 분이 통째로 사라졌다.
3. 못 넣은 사유를 뭉뚱그렸다(`unfitted_scene_message`를 만들어 놓고 안 썼다).
4. `DubbingFit`에 사유를 위치인자로 넣어 `pad_sec`에 문자열이 들어갔다.
5. 거의 맞는 짧은 소리를 안 채워서 그만큼 짧게 나갔다.
6. 호스트 서비스가 모델 하나를 여러 실에서 같이 썼다.

**시험이 결함을 못 잡던 이유도 고쳤다.** 무한 재요청 시험은 같은 함수를 계속
넘겨서 통과했다 — 부모가 매번 새 함수를 넘기게 바꾸니 잡힌다(고치기 전 4번, 뒤 1번).
