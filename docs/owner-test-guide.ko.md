# 편집기 테스트 안내 (루이스 대표님용)

2026-10-10 기준(저장 알림이 클릭을 가리던 문제, 휴대폰 폭의 단축키 안내 잘림은 고쳐서 뺐습니다). 아래 내용은 이미 확인된 것만 적었습니다. 확인하지 못한 것은 4번에 따로 적었습니다.

## 1. 시작하기

- 접속 주소: `http://127.0.0.1:5173/projects` (서버가 켜져 있어야 열립니다)
- **새 프로젝트로 시험하세요.** 0907 프로젝트에는 이전 검증 편집이 되돌리기 기록에 남아 있어서, 되돌리기를 많이 누르면 그 기록까지 거슬러 올라갑니다.
- 프로젝트 목록에서 `+ 새로 만들기`로 시작하거나, 이미 있는 프로젝트(0907 제외)를 열어도 됩니다. 새로 만들면 편집 화면까지 가는 데 분석 시간이 걸릴 수 있습니다.

## 2. 해볼 것 (번호 순서대로)

| 번호 | 무엇을 누르나 | 정상이면 보이는 것 |
|---|---|---|
| 1 | 프로젝트 하나를 열어 편집 화면으로 | 편집 화면이 열립니다. 잠깐 `편집판을 여는 중`이 보일 수 있습니다. |
| 2 | 타임라인의 영상 클립 하나 | 오른쪽 `편집 항목`에 누른 클립의 장면이 나옵니다. 다른 장면이 나오면 안 됩니다. |
| 3 | 스페이스바 | 재생이 시작됩니다. 한 번 더 누르면 멈춥니다. |
| 4 | `재생 빠르기` 칸에서 `2배` 고르고 재생 | 2배 빠르기로 흐릅니다. 완성 영상의 속도는 바뀌지 않습니다. |
| 5 | 멈춘 상태에서 `→` 키를 여러 번 빠르게 | 누른 만큼 한 프레임씩 빠짐없이 움직입니다. |
| 6 | 재생 위치(세로 줄)를 자를 곳에 두고 `Ctrl + B` 또는 가위 모양 `분할` 단추 | 그 자리에서 클립이 둘로 나뉩니다. |
| 7 | 클립 끝의 손잡이를 옆 클립 쪽으로 끌기 | 옆 클립 가까이에서 안내선이 보이고 붙습니다. 놓으면 `저장했어요`가 잠깐 뜹니다. |
| 8 | 장면을 고르고 `Delete` (또는 휴지통 모양 `빼기`) | 장면이 빠지고 그 자리는 빈칸으로 남습니다. |
| 9 | `Ctrl + Z`, 그다음 `Ctrl + Shift + Z` | 방금 편집이 되돌아갔다가 다시 돌아옵니다. 화면의 `실행 취소`·`다시 실행` 단추도 같습니다. |
| 10 | 트랙 머리의 스피커 모양(음소거), 눈 모양(숨기기) 단추 | 그 트랙의 상태가 바뀌고, 다시 누르면 원래대로 돌아옵니다. |
| 11 | `Ctrl + =` / `Ctrl + -`, 그리고 `Shift + Z` | 타임라인이 늘고 줄어듭니다. 전체 보기에서 눈금 글자가 겹치지 않습니다. |

편집할 때마다 화면 위에 `변경 내용을 저장하고 있어요`가 뜬 뒤 `저장했어요`로 바뀌면 정상입니다.

## 3. 단축키

| 키 | 동작 |
|---|---|
| 스페이스바 | 재생 / 일시정지 |
| K / L / J | 멈춤 / 누를수록 빠르게 재생 / 느리게 (캡컷은 거꾸로 재생이에요) |
| ← / → | 한 프레임 뒤로 / 앞으로 |
| ↑ / ↓ | 앞 / 뒤 자른 자리로 |
| Home / End | 처음 / 끝으로 |
| Ctrl + B | 재생 위치에서 나누기 |
| Delete (또는 Backspace) | 고른 장면 빼기 |
| Q / W | 재생 위치 왼쪽 / 오른쪽 잘라 내기 (빈자리는 그대로 둡니다) |
| Ctrl + Z / Ctrl + Shift + Z | 되돌리기 / 다시 하기 (Ctrl + Y도 다시 하기) |
| Ctrl + = / Ctrl + - | 타임라인 늘리기 / 줄이기 |
| Shift + Z (또는 Ctrl + 0) | 영상 전체 보기 |

## 4. 알려진 문제와 아직 안 되는 것

- **트랙 `잠금` 단추는 화면에서만 잠기고 저장되지 않습니다.** 새로고침하면 풀립니다. 예전에 잠금과 `실행 취소`를 함께 쓰다 오래된 편집이 되돌아간 일이 있어서, 원인을 확인하기 전까지는 누르지 않는 것을 권합니다. (조사 중)
- **편집을 짧은 시간에 많이 하면 저장이 느려집니다.** 편집을 20번 몰아쳤을 때 저장에 약 10초가 걸렸습니다. (조사 중)
- **미리보기가 가끔(약 10%) 안 만들어집니다.** 소리가 짧게 나온 경우에는 한 번 자동으로 다시 만들지만, 그 밖의 실패는 직접 다시 눌러야 합니다.
- **장면을 빼면 빈자리가 남습니다.** 뒤 장면이 자동으로 당겨지지 않습니다.
- **0907 프로젝트의 `다시 실행`을 누르면** 시험 때 되돌린 편집이 되살아납니다. 0907에서는 누르지 마세요.
- 재생 빠르기 최고값(8배 또는 4배)은 대표님이 정하셔야 합니다.
- **아직 확인하지 못한 것:** 실제 소리(스피커로 들어 보지 않음), `가로·세로 비교` 화면, 완성된 mp4 영상.
