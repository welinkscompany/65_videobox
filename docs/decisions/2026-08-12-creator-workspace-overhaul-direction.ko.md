## 승인된 제품 방향

- 프로젝트를 먼저 선택한 뒤 `기획 → 자산 → 편집 → 검토 → 출력` 흐름으로 제작한다.
- 전역 메뉴는 `프로젝트`, `내 라이브러리`, `촬영본 정리`, `설정`으로 단순화한다.
- B-roll, 음악, 효과음은 관리 저장소에 복사해 누적하는 개인용 로컬 라이브러리로 운영한다.
- 세 자산 종류 모두 앱 안에서 드래그앤드롭 등록, 자동 분석, 의미 검색, 미리보기와 안전한 삭제를 지원한다.
- 긴 촬영본은 비파괴 분할하고 짧은 촬영본은 가상 결합하며, 유진 제안은 미리보기와 owner 승인을 거친다.
- 자체 편집기에서 컷, 자막, B-roll, 음악, 효과음, 화면 구성, 검토와 출력을 끝낸다.
- 하나의 마스터 편집본에서 가로 16:9와 세로 전체본 9:16을 함께 만든다.
- 세로 하이라이트 9:16은 요청할 때만 생성하는 선택 기능이다.
- CapCut은 필수 후편집 단계가 아니라 선택적 호환·비상 경로다.

## 대체되는 기존 범위

`2026-08-05-dashboard-white-orange-direction.ko.md`의 “자산은 썸네일 그리드이며 목록이 아니다” 조항은 이 결정으로 대체한다.

- 영상: 썸네일 격자
- 음악·효과음: 파형 목록
- 가져오기: 진행 상태 표
- 촬영본 정리: 미리보기·파형·구간 타임라인

이 대체는 자산 종류별 비교·미리보기 방식이 다르고, 자산이 누적될 때 페이지 전체가 길어지는 문제를 막기 위해 승인됐다.

## 완료 판정

테스트 또는 computed style만으로 완료를 선언하지 않는다. 실제 브라우저에서 owner가 프로젝트 생성부터 자산 등록, 촬영본 정리, 직접·유진 편집, 현재 리비전 검토, 가로·세로 출력과 결과 영상 재생까지 수행해야 한다.
