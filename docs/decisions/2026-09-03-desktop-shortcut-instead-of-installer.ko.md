# 설치형 대신 바탕화면 바로가기 (2026-09-03, owner 승인)

앞: `2026-08-30-installed-desktop-shell-tauri.ko.md` (설치형 착수 승인)

## 결정

**설치형(Tauri)은 포기가 아니라 보류하고, 바탕화면 바로가기로 대신한다.**
owner가 "바탕화면 바로가기 만들어줘"로 승인했다.

## 왜

설치형이 주는 것은 **"두 번 클릭해서 켜는 편함" 하나**다. 그런데 그걸 얻으려면

- 코드 서명 인증서를 사야 하고(연 단위 갱신),
- 그래도 Windows Smart App Control이 막을 수 있다(2026-08-31 실측 — clean
  빌드에서 실제로 막혔고 **OS 정책이라 코드로 못 고친다**).

바로가기는 같은 편함을 인증서 없이 준다. 이미 만들어 둔 Tauri 작업은 지우지
않는다 -- 나중에 배포가 필요해지면 그때 인증서를 사면 된다.

## 무엇을 만들었나

| 파일 | 하는 일 |
|---|---|
| `scripts/start-videobox.ps1` | VideoBox 켜고 → 목소리 프로그램 켜고 → 화면 연다 |
| `scripts/install-desktop-shortcut.ps1` | 바탕화면에 바로가기를 만든다(한 번만) |

**목소리 프로그램이 없거나 실패해도 멈추지 않는다.** 자막·편집·완성본은
목소리 없이도 다 되고, 더빙만 "목소리 프로그램을 켜 주세요"라고 말한다.
켜는 데 실패했다고 VideoBox까지 못 쓰게 만들 이유가 없다.

**이미 켜져 있으면 또 켜지 않는다.** 두 번 켜면 8199 포트를 다투다 죽는다.

**창을 숨기지 않는다.** 처음 켤 때는 몇 분이 걸리는데, 창이 없으면 눌렸는지도
모른 채 계속 누르게 된다.

## 실측 (2026-09-03)

- 바로가기가 가리키는 그대로 실행 → 종료 코드 0, 전부 PASS, 화면 열림
- 목소리 프로그램을 내린 뒤 다시 실행 → **자동으로 켜졌다**(chatterbox)
