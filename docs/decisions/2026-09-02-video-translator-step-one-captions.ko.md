# 동영상 번역기 1단계 — 자막만 옮긴다 (2026-09-02)

## 배경

`2026-09-01-capcut-ai-feature-triage.ko.md`가 캡컷 AI 기능 열둘을 추려내며
**다음 큰 것은 동영상 번역기**로 지목했다. owner가 "모두 순서대로 진행해보자"로
착수를 승인했고, 세부 결정은 위임받았다.

## 결정

**1단계는 자막 번역만 만든다.** 목소리 더빙은 2단계로 미룬다.

| 정한 것 | 값 |
|---|---|
| 범위 | 자막만. 원본 목소리는 그대로 둔다 |
| 언어 | 영어·일본어·중국어. 한국어는 목록에 없다(원본이 곧 한국어) |
| 원본 처리 | **지우지 않는다.** 언어별로 나란히 쌓는다 |
| 고르는 자리 | 편집기 속성 패널 `자막 언어` (자막 스타일 바로 아래) |

### 왜 목소리를 미뤘나

자막은 이미 있는 구조(`caption_text`)와 렌더 경로를 그대로 쓴다 — 만드는 것은
번역과 고르기뿐이다. 목소리 더빙은 그 위에 성우 합성·길이 맞추기·입 모양이
전부 새로 붙는 별개의 일이고, 자막이 먼저 있어야 번역문을 읽힐 대본이 생긴다.
순서가 반대일 수 없다.

### 왜 원본을 남기나

번역은 되돌릴 수 있어야 한다. 원본을 갈아치우면 한국어로 돌아갈 방법이 없고,
다시 번역하면 이미 영어가 된 자막을 또 영어로 옮기게 된다. `원본` 칸이 언어
목록의 **첫 자리**인 것도 같은 이유다 — 되돌릴 곳이 안 보이면 눌러 보기가 겁난다.

### 왜 언어를 세션에 적나

이 저장소는 렌더 경로가 둘이고 한쪽만 고쳐서 같은 함정에 두 번 빠진 적이 있다.
그래서 "어느 언어로 낼지"를 렌더 함수 인자로 흘리지 않는다. 세션에 적어 두면
자막을 모으는 **한 자리**에서만 읽으면 되고, 그 아래 모든 출력 경로가 저절로
같은 자막을 본다. 덤으로 선택이 프로젝트에 저장돼 다시 고르지 않아도 된다.

## 범위 밖으로 둔 것

- **목소리 더빙**(2단계)
- **자막 타이밍 재조정** — 언어마다 길이가 달라 원문 구간에 안 맞을 수 있다.
  지금은 원문 구간을 그대로 쓴다. 모델에게 "짧게 옮기라"고 지시해 완화했지만
  없앤 것은 아니다. 실제로 넘칠 때 다시 본다.
- **번역문 직접 고치기** — 지금은 다시 번역하거나 원본으로 되돌리는 두 길뿐이다.
  장면별 손보기는 요청이 나오면 연다.
