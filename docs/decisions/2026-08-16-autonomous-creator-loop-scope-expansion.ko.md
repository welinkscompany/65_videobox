  진행해. 승인하는거야."** 앞선 턴에서 제시한 결정 A·B·C를 모두 승인한 것으로 본다.

## 무엇을 승인했나

### A. 제품 범위를 넓힌다

VideoBox는 더 이상 **편집기만**이 아니다. 목적지는
`추천 → 선택 → 대본 → 확정 → 제작 → 업로드 → 성과 분석 → 다시 추천`이 도는
**영상 운영 도구**다.

`CLAUDE.md` §2.1의 "creator-complete MP4-first 경량 편집기" 경계는 **편집 단계에 한해**
계속 유효하다. 즉 전문 색보정·고급 마스크·임의 키프레임·멀티캠은 여전히 범위 밖이다.
**넓어진 것은 편집 앞뒤(대본·업로드·분석)이지 편집 자체가 아니다.**

### B. 유진이의 금지 조항을 푼다

`implementation-plan` §23.3이 금지하던 **대본·제목 생성과 제안**을 허용한다.

**계속 막는 것 (푸는 범위를 좁게 잡는다):**

- **owner 확정 없이 어떤 장면도 만들지 않는다.** 대본은 제안이고, 제작은 확정 뒤다.
- **owner가 누르지 않은 업로드는 없다.**
- 유진이가 **자기 프로파일이나 코드를 스스로 고치는 것**은 계속 금지한다.
  프로파일이 해시로 고정된 이유가 그것이다. 품질이 오르는 것과 통제가 풀리는 것은 다르다.
- DB·shell·filesystem·credential 직접 접근 금지는 그대로다.

### C. 바깥으로 나가는 것을 승인한다

- **텔레그램**: 유진이를 붙인다.
- **유튜브 업로드**: 허용하되 **owner가 누르는 마지막 게이트를 남긴다.**
  무엇이 언제 어디로 올라갔는지 감사 기록을 남긴다.

`CLAUDE.md` §6의 "외부 게시·업로드는 명시 승인" 조항은 **이 결정으로 충족된 것으로 보되,
개별 업로드마다 사람이 누르는 동작은 없애지 않는다.**

## 사람이 남는 자리 — owner가 직접 지정했다

```
제목 추천 → [사람: 선택] → 대본 → [사람: 확정] → 제작 → [사람: 업로드] → 분석 → 추천
```

**이 세 자리를 설계에서 없애지 않는다.** 자동화의 목적은 사람을 빼는 것이 아니라
사람이 판단할 것만 남기는 것이다. 이건 owner의 원래 표현("내가 그중에서 선택하면",
"확정하면")을 그대로 옮긴 것이다.

## 함께 확인된 사실 — 목소리 복제는 이미 있다

owner가 "깃허브 보이스박스 오픈소스를 붙이자"고 했으나, **재사용 게이트(§8.1)로 확인한
결과 이 저장소에는 이미 실제 목소리 복제가 구현돼 있다.**

- `packages/provider-interfaces/.../local_xtts_provider.py` — **Coqui XTTS-v2**,
  업로드한 음성 샘플을 화자 참조로 쓰는 **진짜 voice cloning**. 완전 로컬.
  주석에 "Windows/Python 3.12에서 end-to-end 동작 확인"이라고 적혀 있다.
- 음성 샘플 업로드 화면과 TTS 듣기 검수 화면도 이미 있다
  (`VoiceTtsSettings.tsx`, 인계 문서 3건).
- 기본값은 꺼져 있다(`enabled: false`, 기본 엔진 `gtts`). XTTS는 ~2GB 모델을
  처음 쓸 때 내려받고 무거운 선택 설치가 필요해서다.

**그래서 새 오픈소스를 붙이는 것은 지금 필요 없다. 다만 진짜 문제가 하나 있다.**

### ⚠ 라이선스 — 매출 목표와 충돌한다

**XTTS-v2는 Coqui CPML 라이선스이고 비상업용이다**(코드 주석에도
"accepting Coqui's non-commercial CPML license"라고 명시돼 있다).
owner의 목표가 이 제품으로 **매출을 내는 것**이므로 그대로 쓰면 문제가 된다.

**"보이스박스"가 무엇인지도 확인이 필요하다.** Meta의 Voicebox는 발표만 되고
공개되지 않았다. GitHub에 `voicebox` 이름의 저장소가 여럿 있고 VOICEVOX(일본어 TTS)와도
혼동되기 쉽다. **owner에게 정확한 저장소 주소를 받은 뒤 라이선스부터 확인한다.**

→ **미결 항목:** 상업적 사용이 가능한 한국어 voice cloning 엔진 선정.
기능 부족이 아니라 **라이선스** 때문에 필요한 작업이다.
