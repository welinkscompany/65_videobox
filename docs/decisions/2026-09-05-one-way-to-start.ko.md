# 새로 시작하는 문은 하나다 (2026-09-05, owner 승인)

이 문서는 `2026-08-28-home-screen-reversal.ko.md`가 만든 **시작 지름길 둘**을
거둔다. 그 문서의 나머지(`/`는 항상 `/projects`)는 그대로다.

## owner가 물은 것과 답한 것

> "시작경로 3 개에서 1개가 무슨말이여?"

첫 화면에 새로 시작하는 길이 셋이었다.

| 단추 | 하던 일 |
|---|---|
| `+ 새 프로젝트 만들기` | 이름을 묻고 → 만든 뒤 편집기 |
| `빈 편집판으로 바로 시작` | 이름 자동 → 편집기 |
| `내 목소리 등록·클론` | 이름 자동 → **편집기** |

**셋이 전부 같은 곳으로 갔다.** 다른 점은 이름을 지금 쓰느냐 자동으로 붙느냐뿐.
설명을 드리고 owner가 **"하나로 합치기"**를 골랐다.

## 무엇을 했나

- 첫 화면 단추는 `+ 새로 만들기` 하나다. 누르면 이름을 묻지 않고 곧바로
  편집기로 들어간다. 이름은 자동으로 붙고 **이름 바꾸기로 언제든 고친다**
  (그 기능은 이미 있었다).
- 이름 입력 폼과 지름길 카드 둘을 걷어냈다. 쓰이지 않게 된 함수·상태도 지웠다.

## `내 목소리 등록·클론`은 기능을 없앤 게 아니다

그 단추는 **목소리 화면을 열지도 않았다.** 이름만 `내 목소리 …`인 프로젝트를
만들고 편집기로 보낼 뿐이었다. 진짜 목소리 등록·클론은 편집기 왼쪽 `오디오`
탭 안에 이미 있다(`VoiceMaterialPanel` → `VoiceTtsSettings`). 없앤 것은
**중복된 문**이지 기능이 아니다.

## 왜 되돌리는가

2026-08-28에 이 지름길들을 만든 이유는 "어떤 방식으로 편집할지 결정을 해야
되잖아"였다. 그 뒤 편집기가 모든 것을 품게 되면서(2026-09-01 미디어 단계 접기,
2026-08-30 이름 안 묻고 편집기로) **셋의 도착지가 같아졌다.** 갈래로 만든 것이
갈래이기를 그만둔 것이다.

owner가 2026-09-04에 지적한 "처음에 영상 제작을 할때 뭘 어떤걸 눌러야할지도
모르겠고"가 이 화면이고, 같은 데로 가는 문 셋이 그 혼란의 일부였다.
캡컷도 첫 화면의 만들기 단추는 하나다.

## 실기 확인

들어갔다.
