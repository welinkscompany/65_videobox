## 승인 대상 — 픽셀이 아니라 방향

owner가 "일단 이걸로 하고, 나중에 개발하면서 디자인이 조금씩 바뀔 것"이라고 명시했다.
따라서 이 승인은 **artifact SHA 고정이 아니라 방향 승인**이다.

기존 `creator-workspace-visual-approval.ko.md`와 `2026-07-20-editor-workbench-visual-approval.ko.md`는
artifact aggregate SHA를 고정하고 변경 시 재승인을 요구했다. 그 방식은 여백 하나만 바꿔도
재승인이 필요해 개발을 막는다. 이 결정은 그 방식을 대체한다.

## 승인된 구조

- 좌측 사이드바에 프로젝트 전환과 주 메뉴(홈·새 영상 만들기·편집·자산·출력)
- 편집 작업판은 좌(자산·대본·자막) / 중앙(미리보기) / 우(유진·속성) 3분할
- 자산은 **썸네일 그리드**로 본다. 목록이 아니다
- 썸네일 위에 길이 배지와 방향 배지(`가로`/`세로`)를 겹친다
- B-roll 무음 상태를 카드에 표시한다
- 자산 필터에 종류(전체·영상·음악·효과음)와 방향(가로·세로)을 함께 둔다
- 타임라인 클립 이름은 사람이 읽는 말로 쓴다
- 유진 추천은 대화 안 인라인 카드로 보이고 `먼저 보기` / `적용` 두 단계를 거친다
- 상태 문구는 창작자 언어로 쓴다. `stale` 대신 `최신 편집 반영됨`

## 재승인이 필요한 것과 아닌 것

개발 중 자연스러운 조정은 재승인 없이 진행한다.

**재승인 불필요:**

- 여백, 모서리 반경, 그림자, 애니메이션 조정
- 컴포넌트 내부 배치 조정
- 문구 다듬기 (`§10.13` 창작자 언어를 지키는 범위에서)
- 반응형 중단점별 세부 조정
- 그리드 열 수 변경

**재승인 필요:**

- 위 색 표의 값 변경
- "배경은 흰색, 오렌지는 강조만" 원칙을 벗어나는 변경
- 3분할 구조를 바꾸는 변경
- 자산을 그리드가 아닌 형태로 되돌리는 변경
- 대비 기준(본문 4.5:1, 비텍스트 3:1) 미달

## 유지되는 제약

- 본문 텍스트 대비 4.5:1 이상, 비텍스트 경계·포커스 3:1 이상
- 상태를 색만으로 구분하지 않는다
- `§10.13` 창작자 언어 규정을 따른다. 개발·시스템 내부 용어를 화면에 쓰지 않는다
- 밀도 규칙은 `2026-07-20-editor-workbench-visual-approval.ko.md`의 승인을 유지한다.
  1920에서 양쪽 dock과 미리보기 720px 이상, 1280–1599에서 dock 하나,
  1280 미만에서 focus 관리 drawer
