# 렌더 디버깅 스크립트

2026-08-22에 ffmpeg `xfade` 필터그래프를 좇을 때 쓰던 것들이다. 컨테이너
데이터 폴더 최상단에 굴러다니던 것을 여기로 옮겼다(2026-09-06 정리).

- `dumpgraph.py` — 렌더러가 실제로 만드는 필터그래프를 찍는다
- `repro.py` — 컨테이너 안에서 정확 미리보기 렌더를 그대로 재현한다

**둘 다 컨테이너 안 경로(`/app/packages/...`)가 박혀 있다.** 쓰려면
`docker exec`로 워크스페이스 컨테이너 안에서 돌려야 한다.

같이 있던 결과물(`g1~g4.mp4`, `x1~x2.mp4`, `*.txt`)은 그때의 산출물이라 지웠다 --
여섯 개는 0바이트였다.
